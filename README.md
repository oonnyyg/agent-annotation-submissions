# elfmap — 离线 ELF 装载审计工具

`elfmap` 在不执行目标程序的情况下，说明 ELF 文件内容将如何映射到虚拟地址，
并报告可疑的页权限（可写且可执行的页）。

## 用法

```
go run ./cmd/elfmap <query.json>
```

查询配置示例：

```json
{
  "elf_path": "./demo.elf",
  "load_bias": "0x0",
  "reads": [{"vaddr": "0x401000", "length": 64}]
}
```

输出为 JSON 报告，包含段映射、按 4096 字节页合并后的权限、`wx_pages`
可疑页列表、入口状态以及每次读取的结果（数据以十六进制返回，并附带
`file`/`zero` 来源区间）。

## 支持范围与规则

- 仅支持小端 ELF64、x86-64 的 `ET_EXEC` 与 `ET_DYN` 文件。
- 映射完全按程序头（`PT_LOAD`）构建，不参考节表。
- 校验程序头表范围、段的文件范围与内存长度：`filesz <= memsz`，
  文件范围不得超出文件实际大小，所有地址计算检查 64 位溢出。
- 对齐值只能为 0、1 或 2 的幂；非平凡对齐要求文件偏移与虚拟地址同余。
- 段内文件数据之后补零；零长度段不占空间。允许文件范围重复，
  拒绝非空虚拟内存范围重叠。
- `ET_EXEC` 装载偏移固定为 0；`ET_DYN` 使用配置中的 `load_bias`，
  且必须满足各段对齐。
- 非零入口必须落在实际可执行段内，零入口标记为 `no_entry`。
- 读取请求长度上限为 65536 字节，可跨相邻段与补零区；触及未映射
  空洞则整次失败。补零区以区间表示，不会按完整虚拟空间分配内存。

## 重要说明

- 本工具**不执行**目标文件的任何代码，不做动态链接，不做重定位，
  仅静态描述装载布局。
- 查询为只读操作，不会改动被审计的 ELF 文件。

## 测试

```
go test ./...
```
