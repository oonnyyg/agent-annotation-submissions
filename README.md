# periodic-pair-distribution

粒子轨迹结构分析工具：在周期边界条件下统计不同组分的径向分布函数（RDF）
与累计配位数（CN）。仅使用 Python 标准库，每帧独立归一化，避免盒子体积
变化带来的归一化偏差。

## 运行

```sh
python -m pair_distribution config.json
```

## 配置（JSON）

```json
{
  "trajectory": "traj.jsonl",
  "pairs": [{"a": "A", "b": "A"}, {"a": "A", "b": "B"}],
  "rdf": {"r_max": 4.0, "n_bins": 40},
  "output_csv": "rdf.csv",
  "summary_json": "summary.json"
}
```

- `pairs`：`a` 为中心种类；`a == b` 表示同种类对。
- `r_max` 不得超过所有帧中最短盒边的一半，否则报错退出。

## 轨迹格式（JSONL，每行一帧）

```json
{"box": [10.0, 10.0, 10.0], "particles": [{"id": 1, "type": "A", "position": [0.1, 0.2, 0.3]}]}
```

- 正交盒，三个盒长必须为正数，否则拒绝该帧。
- 粒子 `id` 与 `type` 集合在所有帧中必须完全一致；缺失、额外或种类
  变化的粒子都会导致报错。
- 坐标允许落在主盒之外，距离始终按最小镜像约定计算。

## 统计约定

- 径向区间左闭右开 `[r_lo, r_hi)`，落在边界上的距离归入右侧区间；
  `r == r_max` 的最远边界不计入。
- 同种类对排除自身，按**有序对**统计（`i->j` 与 `j->i` 各计一次，
  即双计数）；异种类对以第一种 `a` 为中心单向统计。
- 每帧用精确球壳体积 `4/3*pi*(r_hi^3 - r_lo^3)` 和**本帧**体积归一化：
  - 异种类目标密度为 `N_b / V_frame`；
  - 同种类目标密度为 `(N_a - 1) / V_frame`（中心以外的粒子数）。
  - 不同体积帧的计数绝不先混合再统一归一化。
- `g(r)` 为逐帧 `g(r)` 的**等权平均**；配位数为每个中心在半径 `r` 内
  的平均邻居数（逐帧等权平均的累计值）。求和采用 `math.fsum`，
  帧顺序变化不会改变平均结果。
- 任一种类缺失，或同种类粒子不足两个时：该对的分布为空（CSV 中
  `g_r` 列为空），配位数为零。

## 输出

- CSV：每个 `(pair, bin)` 一行，包含区间边界、原始总计数
  `raw_count`、平均 `g_r`、累计 `coordination`，以及每帧原始计数列
  `frame_<i>_count`。
- 摘要 JSON：帧数、粒子数、种类、盒长范围、`r_max` 上限校验、归一化
  约定说明和每个对的状态（是否为空及原因）。

## 单位

工具不假设具体单位制：坐标、盒长与 `r_max` 使用同一长度单位，
输出的 `g(r)` 无量纲，配位数为粒子个数。只要输入自洽（例如全部
使用埃或纳米），结果即自洽。

## 测试

```sh
python -m unittest discover -s tests
```

覆盖跨周期边界的最小镜像距离、变盒长轨迹的逐帧归一化、同种类双
计数、直方图边界归属、缺失粒子与非正盒长的拒绝，以及帧顺序不变性。
