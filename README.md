# BET 比表面积分析工具

仅依赖 Python 标准库（>= 3.12）。从 CSV 读取多个样品同一吸附支路的
相对压力与单位质量吸附量，按 BET 线性变换做最小二乘拟合，自动枚举并
筛选连续拟合区间，输出可复核的面积报告。不预设固定压力范围去掩盖
不适合拟合的数据。

## 用法

```bash
python -m betfit data.csv config.json [-o report.txt]
python examples/make_example.py   # 生成示例输入
python -m unittest discover -s tests
```

退出码：全部样品拟合成功为 0；任一样品无合格区间为 1；输入错误为 2。

## 输入格式

CSV：首列相对压力 `p/p0`（必须在开区间 (0, 1) 内），其余每列为一个
样品的吸附量，单位 mol/g。每个样品按压力升序排列；重复压力、非有限
数值（NaN/Inf）、列数不一致都会带行号报错。

JSON 配置：

```json
{
  "cross_section_nm2": 0.162,
  "min_points": 4,
  "intervals": {"sample_name": {"lower": 0.05, "upper": 0.30}}
}
```

- `cross_section_nm2`：吸附质分子截面积，单位 nm²（如 N₂/77 K 取 0.162）。
- `min_points`：每个拟合区间的最少点数，至少 4。
- `intervals`：可选。为指定样品给出闭区间 [lower, upper]（按相对压力，
  取落在其中的数据点）。手动区间同样必须通过全部筛选，不会被豁免。

## 公式与单位换算

BET 线性形式（x = p/p0，q 为 mol/g）：

```
y = p / (q * (1 - p)) = 1/(q_m * C) + (C - 1)/(q_m * C) * p
```

对区间内点做最小二乘回归得斜率 s 与截距 i（单位均为 g/mol）：

```
q_m = 1 / (s + i)        [mol/g]   单层容量
C   = s / i + 1          [-]       BET 常数
```

比表面积（q_m 乘阿伏伽德罗常数乘截面积，nm² → m² 需乘 1e-18）：

```
S = q_m * N_A * sigma * 1e-18   [m²/g]
```

## 区间筛选与选择

枚举所有至少含 `min_points` 个点的连续区间（或用手动指定区间），
逐一检验：

1. 截距 i > 0；
2. 单层容量 q_m > 0；
3. BET 常数 C > 0；
4. q·(1 − p) 在区间内不下降（Rouquerol 一致性条件）。

自动选择在通过筛选且决定系数 R² 可定义的区间中取 R² 最高者；
并列时依次取点数更多、起始压力更低者。区间内 y 方差为零时 R²
无法定义，该区间不参与自动选择。没有任何合格区间时该样品明确失败。

报告包含：选中区间、拟合参数、比表面积、逐点残差，以及全部候选区间
的参数与通过/拒绝原因，便于复核。

> 注意：以上规则仅是本工具的拟合质量筛选条件，不构成对数据吸附
> 适用性的完整认证。
