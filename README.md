# catenary-clearance

架空悬索方案的本地核算工具：根据两个支点与索长恢复精确悬链线形状，
核算水平张力、支点张力以及与分段线性地形之间的最小竖向净空。
仅使用 Python 标准库（Python >= 3.12）。

## 用法

```sh
python -m catenary_clearance config.json -o outdir -n 201
```

- `config.json`：输入文件（见下）。
- `-o/--outdir`：输出目录，默认当前目录。
- `-n/--samples`：每个方案输出 CSV 的采样点数（默认 201）。
  采样密度只影响 CSV 的疏密，**不影响**报告中的任何极值与合格结论
  （极值均解析求得）。
- `--report`：报告文件名，默认 `report.json`。

输出：

- `report.json`：每个索长方案的求解结果、残差与限值判定。
- `samples_L<索长>.csv`：每个成功方案的采样形状与张力（`x, cable_y, tension`）。

## 输入格式

```json
{
  "span": {"x1": 0.0, "y1": 12.0, "x2": 80.0, "y2": 18.0},
  "linear_density": 1.2,
  "gravity": 9.81,
  "terrain": [[-5.0, 0.0], [30.0, 1.5], [85.0, 0.0]],
  "lengths": [85.0, 95.0, 110.0],
  "limits": {"max_tension": 600.0, "min_clearance": 2.0}
}
```

- `span`：两个支点坐标，要求 `x2 > x1`，可不等高。
- `linear_density`：索线密度（kg/m），必须为正。
- `gravity`：重力加速度（m/s^2），必须为正，默认 9.81。
- `terrain`：地形折线 `[[x, y], ...]`，x 严格递增且覆盖整个跨度。
- `lengths`：待比较的多个索长方案（m），每个必须严格大于支点直线距离。
- `limits`：可选限值，`max_tension`（N）与 `min_clearance`（m）。

单位自洽即可（建议 SI：m、kg/m、m/s^2、N）。

## 模型假设

- 二维自重静力；索均匀、不可伸长，只受自重，无风载、无温度效应。
- 形状为精确悬链线 `y = y0 + a*(cosh((x - x0)/a) - 1)`，非抛物线近似。
- 水平张力 `H = w*a`（`w = 线密度 * g`），任意点张力 `T = H*cosh((x-x0)/a)`，
  最大张力出现在较高支点。
- 净空为竖直方向 `缆索y - 地形y`；对每个地形段同时检查折点与
  段内驻点（缆索斜率等于段斜率处），取全跨最小值。
  净空为负时保留真实负值并将 `collision` 标为 `true`。
- 悬链线顶点可能位于跨度之外；报告同时给出顶点（含 `inside_span`
  标记）与跨内最低点 `span_lowest_point`，不会强行放在跨中。
- 各索长方案独立求解：某一方案无解（如索长不大于弦长）只在该方案
  的 `error` 字段中说明原因，不影响其他方案。

## 数值容差

- 参数求解：对 `sinh(t)/t = sqrt(L^2 - dy^2)/dx` 做牛顿迭代，
  收敛容差 `1e-12`（相对），最多 200 次；`|t| < 1e-3` 时改用级数，
  保证接近拉直（索长仅略大于弦长）时不发生相消误差。
- 求解后核对端点与弧长残差，相对容差 `1e-9`，超限即报错并说明原因。
- 净空与极值均为解析结果，与 CSV 采样密度无关。
