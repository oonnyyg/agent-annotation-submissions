# vehicle-duty-chain：固定班次车辆接续规划器

在全部班次必须执行的条件下，先求**最少用车数**，再在该约束下求**最小空驶里程**，输出逐车有序班次链。

## 输入

- `-trips`：班次 CSV，表头 `id,from,to,depart,arrive`。时刻为 RFC3339（统一按 UTC 处理），班次持续时间必须为正，编号唯一，最多 120 班。
- `-network`：空驶网络 JSON：
  ```json
  {"turnaround_min": 10,
   "arcs": [{"from": "X", "to": "Y", "time_min": 5, "distance_km": 5}]}
  ```
  `turnaround_min` 为统一最短整备时长（分钟）；`arcs` 为有向空驶弧，时间与里程均为非负整数。同站空驶恒为零，无需也不允许在弧表中给出；未提供的点对不可达，不会经第三站绕行。

## 接续规则

前班到达时刻 + 整备时长 + 空驶时间 ≤ 后班出发时刻（恰好到达允许）。空等不计里程。每班最多一个前班和一个后班。不考虑首班出库与末班回库，不限制驾驶员工时。

## 目标优先级与算法

1. **第一目标：最少车辆数。** 以班次为左右两侧建立二部图，每个可行接续为一条边，最大匹配数即最多接续数，`车辆数 = 班次数 − 最大匹配`。
2. **第二目标：在最少车辆方案中最小化总空驶里程。** 接续边费用为空驶里程，用最小费用最大流（SPFA 最短路增广）在最大流（= 最少车辆）前提下取最小费用。这是全局优化，不是局部贪心。

## 确定性与并列规则

- 解析后班次一律按编号字典序排序，求解只依赖排序后的顺序，因此相同输入任意重排后结果一致。
- 并列（费用相同）方案按以下固定规则打破：SPFA 最短路按节点编号（即排序后班次下标）升序扫描邻接边，距离严格更小才更新，等价于优先保留下标较小的接续组合。

## 非法输入

任何非法输入（重复/空编号、非正持续时间、坏时刻、负时长或里程、同站弧、重复弧、超过 120 班、JSON 含未知字段等）都会以非零退出码报错，不输出貌似可行的部分计划。

## 复现

```sh
go run . -trips examples/trips.csv -network examples/network.json
go test ./...
```

输出逐车班次链、每次接续的空驶时间/里程与等待时间，以及总用车数和总空驶里程。测试覆盖：全局最优（反贪心用例）、恰好到达与差一分钟的边界、不可达点对、同站零空驶、输入重排一致性、非法输入拒绝与 120 班规模。
