# ranked-set-enrichment

离线特征集合富集分析工具，仅依赖 Python 标准库，不连接任何在线数据库。
给定按评分排序的特征榜单与若干预定义特征集合，判断每个集合是否集中
在评分榜首（正富集）或榜尾（负富集），并输出可追溯的富集曲线与统计
摘要。

## 安装与运行

要求 Python 3.12+，无第三方依赖。可直接以模块方式运行：

```bash
python -m ranked_set_enrichment.cli \
    --scores scores.csv --sets sets.json \
    --permutations 1000 --seed 1 \
    --summary summary.csv --curves-dir curves/
```

或通过 `pip install .` 后使用 `ranked-set-enrichment` 命令。

## 输入

- **评分 CSV**：必须包含 `feature_id` 与 `score` 两列。特征标识必须唯一，
  评分必须为有限数值（拒绝 `nan`/`inf`/非数值）。内部按评分降序排列，
  同分按标识字典序排序，保证榜单确定。
- **集合 JSON**：`{"sets": [{"name": ..., "members": [...]}, ...]}` 或
  简单的 `{"名称": [成员...]}` 映射。

集合内重复成员自动去重；不在榜单内的成员被忽略并在摘要的
`ignored_members` 列中报告。过滤后为空、或覆盖整个榜单的集合标记为
`not_computable`（摘要中给出原因），不参与置换检验与多重校正。

## 方法

**富集分数**：沿榜单累计游走。命中集合成员时按该成员绝对评分在集合内
归一化后的权重增加（命中权重全零时均分增量）；未命中时等额减少，使游
走终点归零。取绝对值最大的游走值作为有符号富集分数；正负并列取正值，
同值取最早位置。

**置换检验**：固定评分与位置，均匀无放回抽取同样大小的成员位置生成零
分布。采用**双侧经验概率**：统计零分布中绝对分数不少于观测绝对值的次
数，分子分母各加一（`(k+1)/(n+1)`），避免输出零概率。本题不区分正负
尾分别检验，也不复刻完整 GSEA 软件的归一化（NES）与基因集置换口径。

**多重校正**：对所有可计算集合的经验概率做 Benjamini–Hochberg 校正，
报告原始 `p_value` 与校正后 `q_value`。

## 随机复现

`--seed` 固定后结果完全可复现。每个集合的零分布使用独立播种的随机数
生成器，仅依赖种子与集合大小，因此**集合输入顺序或成员书写顺序的改变
不会改变同一集合的置换结果**。

## 输出

- **摘要 CSV**：每个集合一行，含状态、不可计算原因、富集分数、极值位
  置（0 基）、有效成员数、被忽略成员、原始与校正概率。
- **曲线 CSV**（每个可计算集合一个文件，位于 `--curves-dir`）：逐位置
  的 `position, feature_id, score, hit, running_sum`，可直接绘图追溯。
