# image-layer-auditor

离线分析一组**有序的本地未压缩 tar 层**，重建软件镜像的最终文件清单与
每个条目的来源层。全程只读 tar 流，不启动容器，也不向宿主目录解包；
仅使用 Go 标准库。

## 用法

准备一个 JSON 数组，按层顺序列出 tar 文件路径：

```json
["layer0.tar", "layer1.tar", "layer2.tar"]
```

```sh
go build -o auditor .

# 完整报告：逐层新增/删除/变化 + 最终清单
./auditor analyze layers.json

# 仅最终清单（按路径字典序固定排序）
./auditor manifest layers.json

# 单条路径的逐层历史
./auditor history layers.json app/run.sh
```

清单中普通文件记录内容 SHA-256 与最后写入层，符号链接记录原始目标
字符串（绝不跟随），目录只记录类型与来源层。

## 受限模型

- 只支持普通文件、目录、符号链接三种成员；其他类型（设备、FIFO、
  硬链接等）一律拒绝。
- **不审核**权限、属主、时间戳与扩展属性（xattr/ACL），这些元数据
  被读取但从不进入结果。
- 路径按 POSIX 规范化（`path.Clean`），拒绝绝对路径、反斜杠以及任何
  `..` 父目录跳转；同一层内规范化后重名的成员视为非法。
- 只处理未压缩 tar；gzip/zstd 等请先解压后再传入。

## 层语义

- 普通成员覆盖下层同路径；目录被文件或符号链接替换时，其全部后代
  一并移除。
- 缺失的父目录自动补为隐式目录；若父路径上已存在非目录节点，必须由
  本层显式目录成员替换，否则整层拒绝。层内非目录成员再带后代同样拒绝。
- 支持 OCI 删除标记：`.wh.<name>`（空普通文件）删除下层同目录对应
  路径及其后代；`.wh..wh..opq` 清空所在目录的全部下层后代。标记本身
  不进入结果，也不会删除本层新增成员（删除先于普通成员应用）。
- 每层先应用全部删除标记，再按“父先子后”应用普通成员，因此 tar 内
  成员顺序不影响最终视图。
- 整层先完整校验再提交：任何失败都保留上一个成功层的状态并停止，
  不会留下半层状态；报告中的 `stopped`/`error` 字段指示失败位置。

## 逐层报告

每层报告四个列表（均为排序后的路径）：

- `added`：本层新增（含隐式目录）；
- `deleted`：被白名单、不透明目录或类型替换移除；
- `changed`：内容或类型发生变化；
- `rewritten`：内容完全相同、仅来源层更新（不计入内容变化）。

## 测试

```sh
go test ./...
```

覆盖不透明目录、目录↔文件/链接类型替换、符号链接父路径、层校验
失败的原子性、隐式父目录与路径历史。
