# tenpin-score-desk

十瓶保龄球练习馆记分工具（Go 标准库实现）。支持多人各自的多局球，
通过 JSONL CLI 录入投球、更正历史投球并查询一致的记分单。球局以
JSON 文件保存在本地，重启后可继续录入或查询。不做赛程编排。

## 构建与运行

```sh
go build ./cmd/tenpin
go test ./...
```

CLI 从标准输入逐行读取 JSON 命令，逐行输出 JSON 响应。数据目录通过
`-dir` 指定（默认环境变量 `TENPIN_DATA_DIR`，否则 `./tenpin-data`）。

## 命令格式

每行一个命令，`cmd` 必填：

- `{"cmd":"new","id":"g1","player":"Alice"}` 开新局（id 唯一）
- `{"cmd":"roll","id":"g1","pins":10}` 记录一次投球
- `{"cmd":"correct","id":"g1","roll_index":3,"pins":7}` 更正第 4 次投球
  （`roll_index` 从 0 开始）
- `{"cmd":"score","id":"g1"}` 查询记分单
- `{"cmd":"list"}` 列出所有球局

响应为 `{"ok":true,"data":...}` 或 `{"ok":false,"error":"..."}`。
`roll` / `correct` 成功后直接返回最新记分单。

## 记分单字段

`score` 返回：

- `frames[]`：每轮 `rolls`（原始投球）、`score`（已确定轮分）、
  `cumulative`（累计分）。
- `next_frame` / `next_roll`：当前应投位置（1 起计，整局完成时为 0）。
- `complete` / `total`：整局是否完成；`total` 仅在完成后公布。
- `corrections`：成功更正的历史（位置、原值、新值）。

## 待定成绩的含义

全中需要随后两球、补中需要随后一球才能确定轮分。后续投球不足时，
该轮 `score` 为 `null`（待定），**不会按零补齐**。`cumulative` 只在
之前所有轮分都已确定时公布，遇到第一个待定轮即停止。整局未完成时
`total` 为 `null`，不给出伪最终成绩。

## 规则要点

- 前九轮首球全中即结束该轮，否则投两球；第十轮全中获两次补投、
  补中获一次补投，补投不生成新轮，补投前重新摆瓶（瓶数重置为 10）。
- 每球击倒数为 0 到当前剩余瓶数之间的整数；已完成球局拒绝继续投球。
- 更正会保留其后全部原始记录，并从头重新验证整局：若更正使后续
  记录不再合法（例如剩余瓶数不够），整个更正被拒绝，原局保持不变，
  不会擅自删除投球。成功的更正记入 `corrections` 历史。
