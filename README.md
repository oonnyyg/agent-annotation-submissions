# 层级泛化离线统计发布匿名化工具

在保留统计信息与分组匿名约束之间做取舍：为每个准标识列选择统一的向上泛化步数，
使泛化后的等价组同时满足人数与敏感值多样性门槛，并在全部允许步数组合中最小化成本。
本工具不采用简单打码，而是基于层级树的全局泛化加整组抑制。

## 输入

- **CSV**：首列为记录标识，中间一至四列为准标识列，末列为敏感列。
  拒绝缺失值、重复标识、未知叶值与非叶原始值。
- **层级 JSON**：`{"hierarchies": {"列名": {"子值": "父值", ...}}}`，
  每列必须是无环单根树，深度不超过四，根节点无父映射。非树层级（环、多根、断链）会被拒绝。
- **配置 JSON**：

```json
{
  "k": 2,
  "l": 2,
  "budget": 10,
  "weights": {"age": 1, "city": 1},
  "suppressionCost": 3
}
```

`k`（每组最少人数）与 `l`（每组敏感值最少种类数）为正整数，`budget`（抑制预算）为非负整数，
`weights`（各列步数权重）与 `suppressionCost`（每条抑制代价）为正整数。

## 语义

- 每列选择统一步数（0 至该列最大深度），所有记录按同一规则泛化，已到根则保持。
- 按泛化后的准标识组合分组；组内人数 < k 或敏感值种类数 < l 的组被**整组抑制**，
  不会只删除个别敏感值。
- 总抑制条数不得超过预算，且至少保留一行；无满足条件的方案时明确失败。
- 成本 = Σ(列步数 × 列权重) + 抑制条数 × 抑制代价。同成本先取抑制较少者，
  再按配置列顺序取字典序最小的步数向量。输入记录重排不改变方案选择。

## 输出

- **公开 CSV**（`-public`）：仅含泛化后的准标识列与敏感列，不含原始标识与抑制记录，可对外发布。
- **内部报告 JSON**（`-report`）：记录分组检查、逐行去留与成本明细，仅供内部审计，不得公开。

## 命令行

```sh
# 搜索最优方案并输出公开数据与内部报告
go run . anonymize -csv examples/data.csv -hier examples/hier.json -config examples/config.json \
  -public examples/public.csv -report examples/report.json

# 独立核查给定步数方案（按 CSV 准标识列顺序）
go run . check -csv examples/data.csv -hier examples/hier.json -config examples/config.json -steps 1,1
```

## 测试

```sh
go test ./...
```

覆盖敏感值种类不足、层级交叉（跨列叶值、环形/多根层级）、预算无解、重复标识、缺失值与输入重排稳定性。
