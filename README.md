# survey-margin-raking

分类边际配权（raking / 迭代比例调整，IPF）工具。仅使用 Python 标准库，
根据已知总体边际分布调整调查样本权重，并明确报告结果是否真正达到目标。

## 输入

**样本 CSV**：必须包含 `id`（唯一）与 `weight`（正的有限初始权重）列，
其余列视为分类字段，取值不能为空。

**目标 JSON**：

```json
{
  "tolerance": 1e-9,
  "max_iterations": 500,
  "margins": [
    {"name": "age", "fields": ["age"],
     "targets": {"Y": 60, "O": 40}},
    {"name": "age_sex", "fields": ["age", "sex"],
     "targets": {"Y|M": 30, "Y|F": 30, "O|M": 25, "O|F": 15}}
  ]
}
```

- 边际可对应单字段或字段组合；组合边际的类别键按字段顺序用 `|` 连接。
- 目标值必须为非负有限数；各边际的总量必须相同且为正。
- JSON 中的重复键（含重复类别）会被拒绝。
- 样本中出现的每个类别组合都必须在对应边际中有目标（可为 0），
  否则拒绝；目标中存在但样本中不存在的类别允许出现（见下文不可达规则）。

## 算法与停止规则

每轮按配置文件中 `margins` 的**声明顺序**逐个边际调整：对边际的每个类别，
把该类所有样本权重乘以 `目标总量 / 当前总量`。迭代顺序会影响中间路径，
但收敛判定与顺序无关（见下）。

- **零目标**：该类别样本权重直接归零。
- **不可达**：正目标没有样本支持，或当前类别权重已被（冲突的零目标）
  全部归零时，立即以 `unreachable` 状态失败——不会制造新样本。
- **溢出**：任何权重变为非有限值时以 `overflow` 状态失败。
- **收敛判定**：每轮结束后重新计算**所有**边际（不是只检查最后调整的
  边际），取最大残差 `|实得 - 目标| / max(目标, 1)`，不超过
  `tolerance` 才标记 `converged`。
- **未收敛**：达到 `max_iterations` 上限仍不满足容差时标记
  `not_converged`，绝不把近似结果标成合格。

每轮的最大残差及其所在边际/类别都会记入诊断历史；结构性矛盾（如冲突的
零目标）会保留在诊断中，冲突目标不会被静默删除。

## 输出

成功（退出码 0）时向输出目录写入：

- `weights.csv`：逐样本 `initial_weight`、`final_weight` 及相对初始值的
  倍率 `multiplier`。
- `margins.csv`：每个边际每个类别的目标值、实得值、绝对残差，附状态、
  迭代轮数、权重总和与有效样本量
  `ESS = (Σw)² / Σw²`。

失败（退出码 1）时只写 `diagnostics.json`（状态、失败位置、逐轮最大残差
历史），**不会覆盖**已有的成功结果文件。输入非法时退出码为 2。

## 用法

```sh
python -m raking samples.csv targets.json --out-dir out
python -m unittest discover -s tests   # 运行测试
```
