# ancestral-character-parsimony

祖先性状重建工具：在给定**有根演化树**（允许多分叉）和叶节点离散性状观测的
条件下，用 Sankoff 动态规划求出**总变化代价最小**的一套联合节点赋值。工具不
搜索、不修改树结构，也不使用分支长度；结果是最小代价赋值，不是概率或置信度。

仅使用 Python 标准库（Python ≥ 3.12）。

## 用法

```bash
python -m ancestral_parsimony --tree tree.json --traits traits.csv --costs costs.json
```

示例输入见 `examples/`。

## 输入格式

### 树（JSON）

```json
{"nodes": [{"id": 1, "children": [2, 3]}, {"id": 2}, {"id": 3}]}
```

- 每个节点有唯一整数 `id`；`children` 可省略（表示叶子），数量不限（允许多分叉）。
- 必须恰好一个根（不是任何节点的孩子）。
- 环路、多父节点、重复编号、悬空引用和不连通结构都会被拒绝。

### 性状（CSV）

```csv
id,limbs,wings
2,a,?
3,b,a
```

- 首列必须是 `id`，其余每列一个离散性状。
- 每个叶子必须恰好出现一行；**缺行是错误**，不会被当作未知。
- 未知观测写作 `?`，该叶子在该列可取任意状态；已知叶子的状态不得改变。
- 非叶子节点不允许出现在数据中。

### 代价模型（JSON）

```json
{"states": ["a", "b"], "matrix": [[0, 2], [3, 0]]}
```

- 所有性状列共享同一套状态（最多 6 种）和同一个转换代价矩阵。
- `matrix[i][j]` 是父状态 `i` 到子状态 `j` 沿一条边的代价；允许非对称。
- 代价必须非负、对角为零、矩阵完整（n×n），否则明确拒绝。
- 观测值不在状态集合中也会被拒绝。

## 算法与并列规则

对每列性状独立运行 Sankoff 动态规划：自底向上计算每个节点在每种状态下的
子树最小代价，根节点的最小值即为该列最优得分。回溯得到的是**一套联合最优
赋值**：先定根，再在父状态已确定的约束下为每个子节点选择达到约束最小值的
状态，而不是各节点独立取最低代价（那样可能产生不兼容组合）。

并列时的确定性规则：

1. 根节点在所有最优状态中取**字典序最小**的状态。
2. 自顶向下，每个子节点在父状态约束下的所有最优选择中取字典序最小状态。
3. 子节点按编号排序处理，输入中 `children` 的排列顺序不影响结果。

## 输出

- **节点性状表**：每个节点（含内部节点）在每列的重建状态。
- **逐分支变化代价**：每条边在每列的代价及合计。
- **得分汇总**：每列最小总代价与全树总分。逐分支代价重新相加等于各列最优
  值，各列相加等于全树总分（程序内部也做了断言校验）。

## 测试

```bash
python -m unittest discover -s tests
```

覆盖多分叉树、未知观测、非对称有向代价、并列规则、联合回溯一致性，以及
树 / 数据 / 代价矩阵的各类非法输入。
