# Discrete Mass Transport

纯 Python 标准库实现的离散分布比较工具：把一组网格位置上的质量搬运到另一组
位置，求满足供需约束的**全局最小总成本**，并输出逐路径的整数搬运计划。
不依赖任何优化软件包。

## 输入

**分布 CSV**（源与目标各一份，必须含表头 `id,x,y,mass`）：

```csv
id,x,y,mass
s1,0,0,6
s2,10,0,4
```

- `id`：唯一标识符（同一坐标允许不同 id）。
- `x, y`：二维整数坐标。
- `mass`：非负整数质量；零质量位置可保留，会出现在守恒复核报告中。
- 每边最多 32 个位置；两边总质量必须相等且为正，非法数据在求解前被拒绝。

**配置 JSON**：

```json
{
  "cost_metric": "manhattan",
  "disabled": [["s1", "t2"]]
}
```

- `cost_metric`：`"manhattan"`（|dx|+|dy|，默认）或 `"sqeuclidean"`
  （dx²+dy²）。单位成本即两点间的该距离，均为整数。
- `disabled`：禁用的 `[源id, 目标id]` 组合，这些路径不得出现正运输量。

## 运行

```sh
python -m transport.cli sources.csv targets.csv config.json
```

退出码：`0` 成功并打印方案；`1` 约束导致不可行（明确报告，不输出部分流量
充当完整方案）；`2` 输入数据非法。

## 输出

- 逐路径整数运输量：`源 -> 目标: 数量 @ 单位成本 = 路径成本`。
- 总成本与平均成本（总成本 ÷ 总质量）。
- 逐点守恒复核：每个源的运出量、每个目标的接收量与输入逐一比对。

## 算法与确定性

采用二分网络上的连续最短路（SSP）最小费用流：每轮沿当前最便宜的增广路按
瓶颈批量运输，因此大质量按批量处理，**不会展开成逐个单位对象**。最短路
允许后续迭代调整（撤销）此前的分配，保证全局最优而非最近目标贪心。

最优解不唯一时，Dijkstra 按 (距离, 节点序号) 弹出、节点序号遵循输入顺序，
因此确定性地偏好**先列出的源到先列出的目标**的路线；同样输入重复运行结果
完全一致。

## 测试

```sh
python -m unittest discover -s tests
```

覆盖：输入校验、贪心陷阱（需要撤销先前分配）、禁用路径（绕行与不可行）、
大质量批量缩放（10⁹ 级不展开）、拆分配送、重复运行确定性、CLI 端到端。
