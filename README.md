# regionaudit — 园区区域几何审计工具

本地命令行工具：校验带孔多边形区域的几何合法性，输出逐区域检查报告，
并用与面积报告一致的边界语义对查询点进行归属分类。仅使用 Go 标准库。

## 运行

```sh
go run ./cmd/regionaudit input.json   # 从文件读取
cat input.json | go run ./cmd/regionaudit   # 从标准输入读取
go test ./...                          # 运行测试
```

## 坐标约定

坐标为整数平面坐标，绝对值不超过 1,000,000，**不**解释为经纬度。
所有拓扑判定（相交、相切、包含、边界）均使用精确整数运算，无浮点误差。

## 输入 JSON 协议

```json
{
  "regions": [
    {
      "id": "r1",
      "rings": [
        [[0, 0], [10, 0], [10, 10], [0, 10], [0, 0]],
        [[2, 2], [4, 2], [4, 4], [2, 4], [2, 2]]
      ]
    }
  ],
  "points": [{"id": "p1", "x": 6, "y": 6}]
}
```

- `rings[0]` 为外环，其余为孔洞。环必须显式闭合（首末点相同），至少
  3 个不同顶点。顶点可写作 `[x, y]` 数组或 `{"x":..,"y":..}` 对象。
- 不要求统一环绕方向；反转任一环方向不改变校验与度量结果。

## 输出 JSON 协议

```json
{
  "regions": [
    {
      "id": "r1",
      "valid": true,
      "area": 96,
      "centroid": [5.0833, 5.0833],
      "perimeter": 48
    },
    {
      "id": "bad",
      "valid": false,
      "errors": [{"ring": 0, "edge": 3, "message": "ring is not explicitly closed..."}]
    }
  ],
  "points": [
    {"id": "p1", "results": {"r1": "inside"}}
  ]
}
```

- 每个区域独立校验：合法区域照常给出 `area`（外环减孔洞的净面积）、
  `centroid`（面积形心）、`perimeter`（外环周长加所有孔周长）；非法
  区域给出定位到环与边的 `errors`，不影响其他区域，也不参与点归属。
- `edge` 为环内边索引：边 `i` 连接输入顶点 `i` 与 `i+1`。
- 点归属按区域分别报告（区域允许重叠，不做唯一归属），取值为：
  - `inside`：严格在区域内部（在外环内且不在任何孔内）；
  - `outside`：在区域外部，**包括孔洞内部**；
  - `outer_boundary`：恰好落在外环边界上；
  - `hole_boundary`：恰好落在某孔洞边界上。

## 合法性规则

- 环必须显式闭合、至少 3 个不同顶点；拒绝零长边、零面积环、自交。
  非相邻边不得有任何接触（交叉、相切、重叠均非法）；相邻边只能共享
  一个公共端点（共线回折算非法，共线直行允许）。
- 每个孔洞必须严格位于外环内部，不得触碰外环；孔洞之间不得相交、
  相切或互相包含（按整环边集判定，不只看首点）。

## 数值误差范围

- 拓扑判定与点归属：精确整数运算，零误差。
- `area`：精确整数鞋带公式的二分之一，误差为 0（面积恒为 0.5 的
  整数倍，可精确表示）。
- `centroid`：形心分子用 float64 累加，相对误差 < 1e-9；坐标量级
  1e6 时绝对误差约 1e-9 以内。
- `perimeter`：各边欧氏长度 float64 求和，相对误差 < 1e-12。
- 顶点数假设在常规规模（万级以内）；极端坐标下单项形心分子接近
  int64 上限，故形心采用浮点累加以避免溢出。
