# tzaudit — TZif 转换核对工具

`tzaudit` 依据给定的 TZif（RFC 8536）v2/v3 时区文件，核对绝对时刻与本地钟面时间之间的对应关系。仅使用 Go 标准库，不读取操作系统时区，不联网获取时区数据库。

## 运行

```
go run ./cmd/tzaudit query.json
```

结果以 JSON 写到标准输出；文件级错误（无法解析、格式非法）写到标准错误并以非零码退出。

## 输入格式

```json
{
  "tzif": "path/to/local-file.tzif",
  "queries": [
    {"type": "at", "unix": 2200000000},
    {"type": "local", "local": "2039-09-19T02:00:00"},
    {"type": "intervals"}
  ]
}
```

- `tzif`：本地 TZif 文件路径（相对路径相对于当前工作目录）。
- `queries`：查询数组，彼此独立；单条失败只影响该条结果。
  - `at`：绝对时刻 → 本地时间。`unix` 为 UTC 秒。返回本地钟面、所用偏移（秒）与时区缩写。转换瞬间使用新类型。
  - `local`：本地钟面 → 全部绝对时刻。`local` 格式为 `YYYY-MM-DDTHH:MM:SS`。返回窗口内全部匹配的 UTC 秒（升序）及各自偏移；正向跳变造成的空缺返回 `gap`（本地时间左闭右开范围）；回拨造成的重复保留全部候选，不自动挑选。
  - `intervals`：列出窗口内各恒定偏移区间 `[start_unix, end_unix)` 及边界变化。

## 有效窗口

服务窗口为**首次到末次 64 位转换的左闭右开区间** `[first, last)`。末次转换安装的类型本身不被服务（其后的尾部未来规则不予解释）。窗口外的查询被明确拒绝并返回错误，绝不假设末次偏移永久有效。

## 文件要求与校验

- 仅支持 v2、v3 文件，一律依据第二个（64 位）数据块计算，可正确跨越 2038 年。
- 文件至少包含两次转换。
- 校验块长度（截断）、转换记录严格递增、类型下标与缩写字符串引用范围；错误信息指出字节偏移。
- 带闰秒记录（leapcnt > 0）的文件被拒绝。

## 不支持的特性

- TZif v1 文件（无 64 位数据块）。
- 闰秒。
- 尾部 POSIX TZ 字符串中的未来规则推断。
- 偏移变化不假设为一小时；偏移计算完全来自类型记录，从不使用夏令时标记代替。

## 测试

```
go test ./...
```

测试覆盖：2038 年之后的转换、非整小时偏移（+08:45/+09:15）、转换瞬间的新类型语义、正向跳变缺口、回拨重复候选、窗口边界拒绝，以及截断/乱序/闰秒/越界引用的字节级报错。
