# fourbar-motion-audit

平面四杆机构位置与速度计算工具。仅使用 Python 标准库，不做动力学与动画。

## 机构约定

- 固定铰点 `O1` 在原点，`O2` 在 `(ground, 0)`（水平地杆）。
- 输入杆 `crank` 绕 `O1` 按逆时针角 `theta`（弧度）定位活动铰点 `A`。
- 输出活动铰点 `B` 由连杆圆（圆心 `A`，半径 `coupler`）与输出杆圆
  （圆心 `O2`，半径 `rocker`）的交点确定。
- 四根杆长必须均为正。

## 装配分支

两圆一般有两个交点。用向量 `A->O2` 与 `A->B` 的叉积符号选择分支：
`branch = +1` 取叉积为正，`-1` 取叉积为负。整个角度序列固定使用所选
符号，不逐点换支，也不用最近点搜索掩盖无解。

## 构型状态

- `ok`：正常构型，位置与速度均有效。
- `singular`：两圆相切（或雅可比奇异），构型唯一但速度不确定；
  只保留位置，速度字段为空，不以巨大有限值代替。
- `unreachable`：两圆分离或内含，无交点，不可装配。
- `ambiguous`：两圆重合（`d = 0` 且 `coupler == rocker`），构型不唯一。

负的根号值不会被强行取绝对值继续计算。

## 单位与奇异判据

- 角度：弧度；角速度：弧度/秒；长度单位任意但需自洽。
- 奇异判据：速度雅可比行列式 `det = cross(B-A, B-O2)` 满足
  `|det| <= 1e-9 * |B-A| * |B-O2|` 时判定奇异。
- 位置相切判据：交点高度平方 `h^2 <= (1e-9 * coupler)^2`。

## 测点

可选测点以连杆局部坐标 `(u, v)` 指定：原点在输入活动铰点 `A`，
横轴沿连杆指向 `B`，纵轴为横轴左转 90 度。输出测点位置与速度，
并在诊断 JSON 中给出长度约束残差与速度约束残差。

## 用法

```
python -m fourbar input.json --csv out.csv --diag diag.json
```

输入 JSON（见 `examples/sample.json`）：

```json
{
  "ground": 4.0, "crank": 1.0, "coupler": 3.0, "rocker": 2.5,
  "branch": 1,
  "omega": 2.0,
  "angles": [0.0, 0.1, 0.2],
  "probe": {"u": 1.5, "v": 0.2}
}
```

- `omega` 为恒定输入角速度；也可用 `"omegas": [...]` 逐角指定。
- CSV 每行一个构型：角度、状态、铰点坐标、两从动杆角速度、
  `B` 点速度与测点位置/速度（奇异时速度列为空）。
- 诊断 JSON 含单位说明、状态汇总与逐角残差。

## 测试

```
python -m unittest discover -s tests
```

覆盖双分支符号一致性、切点奇异、不可达、重合不唯一、
速度有限差分校验与测点局部坐标。
