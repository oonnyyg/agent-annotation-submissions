# Green-Ampt 降雨入渗计算器

在均质土壤假设下，用 Green–Ampt 模型回放分段恒定雨强的降雨过程，
输出可核对的入渗与径流过程表及水量汇总。仅依赖 Python 标准库。

## 用法

```
python main.py RAIN.csv SOIL.json [--tol 1e-9] [--max-iter 100]
python -m unittest test_greenampt.py   # 运行测试
```

- `RAIN.csv`：含表头 `t_start,t_end,intensity`，时间单位为小时，
  雨强单位为 mm/h。时段必须首尾相接，程序检查负雨强、时段重叠、
  缺口及非正时长。
- `SOIL.json`：`{"ks": ..., "psi": ..., "delta_theta": ...}`，
  分别为饱和导水率 [mm/h]、湿润锋吸力水头 [mm]、初始含水率差 [-]。
  三者必须为正，且 `delta_theta <= 1`。
- `--tol` / `--max-iter`：隐式累计关系求解的误差容限与迭代上限；
  无法收敛时程序明确报错并以非零码退出。

示例见 `examples/`，运行 `python main.py examples/rain.csv examples/soil.json`。

## 求解关系

记 `M = psi * delta_theta`，累计入渗量为 `F` [mm]。

- 入渗能力：`fp = Ks * (1 + M / F)`。`F = 0` 时取极限 `+inf`，
  即任何有限雨强起初都能全部入渗，不发生除零。
- 积水点：当雨强 `i > Ks` 时，能力降至 `i` 对应的累计入渗量
  `F_p = Ks * M / (i - Ks)`。若段内供水使 `F` 达到 `F_p`，
  转换时刻为 `t_p = t_start + (F_p - F_start) / i`，
  段内只在此之后才按入渗受限计算（不会把整段按起点能力处理）。
- 入渗受限阶段：以积水状态 `(F_p, t_p)` 为锚点，隐式累计关系为
  `Ks * (t - t_p) = (F - F_p) - M * ln((F + M) / (F_p + M))`。
  给定段末时刻用牛顿迭代（带二分保护）反解 `F`。
- 超过能力的雨强立即计为径流；无雨时段累计入渗保持不变，
  后续降雨从原状态继续。

输出表在**每个段边界**和**段内积水转换时刻**各给出一行状态，
末尾汇总总降雨、总入渗、总径流并检查水量闭合
（`降雨 = 入渗 + 径流`）。同一恒定雨强拆成更细时段后，
结果在求解容限内一致（有对应单元测试）。

## 模型限制

- 均质土壤、恒定参数；不模拟土壤水分再分布。
- 不考虑地表蓄水：超渗雨水立即成为径流。
- 不考虑蒸发、蒸腾与地下水排泄。
- 雨强在段内恒定，段间可突变；时间序列必须连续无缺口。
