# external-stable-table-sort

离线大表整理工具：把多份 CSV 按业务键**稳定排序**，在有限记录缓冲下完成多路归并与按键去重，输出一份 CSV 和处理统计。纯 Go 标准库实现。

## 运行方式

```sh
go run . -rules rules.json -out output.csv [-stats stats.json] input1.csv input2.csv ...
```

- `-rules`：JSON 规则文件（必填）。
- `-out`：输出 CSV 路径（必填）。只有全部处理成功后才原子替换目标文件；失败时保留旧输出。
- `-stats`：统计输出路径（可选，缺省打印到标准输出）。
- 位置参数：输入 CSV 文件列表。文件顺序与文件内记录顺序共同定义**原始次序**。

## 规则格式

```json
{
  "keys": [
    { "column": "dept",  "type": "text",    "order": "asc",  "empty": "last"  },
    { "column": "score", "type": "decimal", "order": "desc", "empty": "first" }
  ],
  "dedup": true,
  "memoryRecords": 10000,
  "mergeFanIn": 8
}
```

- `keys`：排序键列表，至少一个，按优先级排列。
  - `column`：表头列名（所有输入文件的表头必须完全一致）。
  - `type`：`text`（字符串比较）或 `decimal`（有限十进制数值比较，基于 `math/big.Rat`，无浮点误差，支持 `1e2` 等形式）。
  - `order`：`asc` / `desc`。
  - `empty`：空字段位置 `first` / `last`，独立于升降序；空字段不参与数值转换。
- `dedup`：按完整排序键去重，仅保留原始次序最早的一条，其余非键字段随该记录保留。
- `memoryRecords`：内存块最多容纳的记录数，正整数（>= 1）。
- `mergeFanIn`：每轮最多打开的归并输入数，>= 2。

## 行为说明

- **稳定性**：排序键全部相等的记录保持原始次序，包括跨文件与跨分块的相等记录。实现上为每条记录分配全局递增序号，随临时块持久化，作为比较的最终兜底。
- **外排**：按 `memoryRecords` 分块读入、内存排序后写临时有序块；随后以不超过 `mergeFanIn` 的扇入做多轮归并，每轮只同时打开当轮参与归并的块文件。不会一次加载全部输入，也不会同时打开全部块。不同块大小与扇入产生完全相同的输出。
- **CSV**：使用 `encoding/csv`，正确处理带引号、内嵌换行与转义引号的记录。
- **错误定位**：十进制类型错误会报告文件名与逻辑记录号（不含表头，从 1 起），不会退化为字符串排序。
- **原子输出**：临时块与临时输出都创建在输出目录下的 `.sort-tmp-*` 目录中（同卷，保证 rename 原子性）；成功后替换目标文件；任何失败都保留旧输出并清理本次临时文件，不触碰其他文件。
- **统计**：输出 `read`（读取记录数）、`kept`（保留记录数）、`dropped`（去重删除记录数）。
