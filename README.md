# regionaudit — 园区区域几何审计工具

读取区域集合与查询点的 JSON，逐区域检查带孔多边形的几何合法性，
输出面积/形心/周长报告以及每个查询点的归属结果。坐标是绝对值不超过
一百万的整数平面坐标（不解释为经纬度），全部几何谓词使用精确整数
（int64）运算，不存在浮点舍入导致的误判。

## 运行

```sh
go run ./cmd/regionaudit input.json   # 或从标准输入读取
go test ./...                          # 运行测试
```

示例输入见 `testdata/sample.json`。

## 输入协议

```json
{
  "regions": [
    {
      "id": "alpha",
      "rings": [
        [{"x": 0, "y": 0}, {"x": 10, "y": 0}, {"x": 10, "y": 10}, {"x": 0, "y": 0}],
        [{"x": 2, "y": 2}, {"x": 4, "y": 2}, {"x": 4, "y": 4}, {"x": 2, "y": 2}]
      ]
    }
  ],
  "queries": [{"x": 1, "y": 1}]
}
```

- 每个区域第一个环为外环，其余为孔洞；环方向任意（顺时针/逆时针均可）。
- 环必须显式闭合（首尾点相同）且至少有三个不同顶点。

## 输出协议

```json
{
  "regions": [
    {
      "id": "alpha",
      "valid": true,
      "area": 92,
      "centroid": [4.5, 4.6],
      "perimeter": 40.1
    },
    {
      "id": "broken",
      "valid": false,
      "issues": [{"ring": 0, "edge": 2, "message": "edge 2 intersects or touches edge 0"}]
    }
  ],
  "queries": [
    {
      "point": {"x": 1, "y": 1},
      "results": [{"region": "alpha", "location": "inside"}]
    }
  ]
}
```

- `issues[].ring` 为环编号（0 为外环），`edge` 为环内边编号（从 0 开始，
  边 i 连接顶点 i 与 i+1）；与具体边无关的问题省略 `edge`。
- 合法区域报告 `area`（外环减孔洞的净面积）、`centroid`（净面积形心
  `[x, y]`）、`perimeter`（外环与孔洞周长之和）。反转任一环方向结果不变。
- 非法区域不参与点归属；其余合法区域照常出报告。
- `location` 取值：`inside`、`outside`、`outer_boundary`、`hole_boundary`。
  孔内部属于区域外部（`outside`）。不同区域允许重叠，每个查询点按区域
  分别给出结果，不做唯一归属。

## 合法性规则

- 拒绝未闭合、不同顶点少于 3 个、零长边、零面积的环。
- 拒绝自交：非相邻边不得相交、相切或重叠；相邻边只能共享一个端点
  （共线相邻边视为重叠/尖刺，非法）。
- 孔洞必须严格位于外环内部，不得触碰外环；孔洞之间不得相交、相切或
  互相包含（通过边对相交检测加包含检测共同判定，不只看首点）。

## 数值误差范围

- 点归属、线段相交、包含关系等所有判定均为精确整数运算，无误差。
- `area` 由整数鞋带公式精确求得（整数或 *.5），以 float64 输出，
  在坐标 |v| ≤ 1e6 时精确无舍入。
- `centroid` 与 `perimeter` 使用 float64 累加，相对误差不超过约 1e-9。
