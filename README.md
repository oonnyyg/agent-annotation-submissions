# bmpintake — 旧式 BMP 离线接收工具

纯 Go 标准库实现，不调用任何外部图像程序。读取一个 BMP 文件和一份 JSON
配置，把图像解码为统一坐标（左上角原点、自上而下）的灰度栅格，发布二进
制 PGM 图像和 JSON 摘要。所有结构性错误都会报告出错字节在文件中的偏移。

## 运行

```
go run ./cmd/bmpintake config.json
```

配置示例：

```json
{
  "input": "in.bmp",
  "outputPGM": "out.pgm",
  "outputSummary": "out.json",
  "maxPixels": 4000000,
  "crop": { "x0": 10, "y0": 5, "x1": 200, "y1": 100 }
}
```

- `input` / `outputPGM` / `outputSummary`：必填路径。
- `maxPixels`：必填，解码后图像像素数上限，超过即拒绝。
- `crop`：可选，以左上角为原点的半开矩形 `[x0,x1) × [y0,y1)`，
  越界或为空即拒绝；缺省使用整幅图像。

全部校验成功后才发布输出文件；目标文件已存在时拒绝覆盖（先写临时文件
再原子改名）。

## 支持的 BMP 范围

- 仅 40 字节 `BITMAPINFOHEADER`；文件头尺寸字段必须与实际文件大小一致。
- 24 位未压缩（`BI_RGB`）：扫描行按 4 字节补齐，按 BGR 解释；高度为正
  （自下而上）或为负（自上而下）均可。
- 8 位未压缩（`BI_RGB`）：调色板索引，调色板大小取 `biClrUsed`（为 0 时
  取 256），索引越界即拒绝并报告字节位置。
- 8 位 RLE8（`BI_RLE8`）：仅正高度（自下而上）。支持：
  - 重复段（`count, value`）；
  - 绝对段（`0, n≥3` 后跟 n 个字面字节，奇数时补一个偶数字节）；
  - 换行（`0,0`）、位图结束（`0,1`）、坐标跳跃（`0,2,dx,dy`）；
  - 未写入的位置使用调色板 0 号颜色。

其余位深、压缩方式、平面数或信息头尺寸一律明确拒绝。

## 完整性校验

- 游程不得跨越行宽，delta 跳跃不得越出图像。
- 区分“流在命令边界结束但缺少结束标记”与“命令中途被截断”，两者分别
  报错；非法调色板索引、游标越界同样拒绝并给出字节偏移，绝不用零填充
  掩盖损坏。

## 输出协议

- PGM：二进制 `P5`，最大灰度 255。灰度公式为
  `(299·R + 587·G + 114·B + 500) / 1000`（整数除法），结果 0–255。
- 摘要 JSON：

```json
{
  "width": 190,
  "height": 95,
  "histogram": [ /* 256 个灰度级的完整直方图 */ ]
}
```

尺寸与直方图均统计裁剪后的图像。

## 测试

```
go test ./...
```

覆盖行补齐、正/负高度方向、RLE8 重复段/绝对段/跳跃/默认填充、各类损坏
