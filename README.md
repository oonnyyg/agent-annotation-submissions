# cross_spectrum — 双路同步信号互谱分析工具

仅用 Python 标准库实现的 Welch 平均互谱分析器。读取双通道采样 CSV 与
JSON 配置，输出单边频谱 CSV 与分段诊断 JSON，用于找出两路信号的共同
频率成分及其相位关系。

## 用法

```bash
python -m cross_spectrum data.csv config.json \
    --spectrum spectrum.csv --diagnostics diagnostics.json
```

### 输入 CSV

两列采样数据（可带一行表头），每行一个等间隔采样点，按从零开始的
样本序号定位。空单元格、`NaN`、`NA`、`null` 视为缺测。

### 配置 JSON

```json
{
  "sample_rate": 256.0,
  "segment_length": 256,
  "overlap": 128,
  "nfft": 256,
  "window": "hann"
}
```

- `sample_rate`：采样频率（Hz），必须为正的有限值。
- `segment_length`：段长，3–512。
- `overlap`：重叠样本数，非负且小于段长。段从首个样本起按
  `segment_length - overlap` 的固定步长取，末尾不足整段的部分丢弃。
- `nfft`：变换长度，不得短于段长；零填充只发生在乘窗之后。
- `window`：`rect`（矩形窗）或 `hann`（周期 Hann 窗）。

## 算法说明

1. **分段与缺测**：任一通道在某段内含缺测样本即跳过整段，绝不拼接
   缺口两侧的数据。没有有效段时明确报错失败。
2. **预处理**：每段两路分别去均值，乘窗，再零填充到 `nfft`。
3. **谱估计**：对每段计算 DFT，自谱 `Pxx = |X|²/(fs·Σw²)`，复互谱
   `Sxy = conj(X1)·X2/(fs·Σw²)`；先对各段自谱与复互谱分别平均，
   再由平均结果计算相干 `|Sxy|²/(P1·P2)`——**不**平均每段相干。
4. **单边谱**：除直流与（存在的）奈奎斯特频点外，各频点幅值翻倍。
5. **空值规则**：自谱乘积为零时相干为 null；互谱为零时相位为 null，
   不伪造零相位或满相干。

### 相位正负约定

互谱定义为 `Sxy = conj(X1)·X2`，相位 `phase = arg(Sxy)`（弧度，
取值 `(-π, π]`）。**正值表示通道 2 超前通道 1**（通道 2 的相位更
大），负值表示通道 2 滞后。例如通道 2 相对通道 1 延迟 `Δt` 时，
频率 `f` 处相位为 `-2πf·Δt`。

### 频谱单位

- 自谱 `psd_ch1`/`psd_ch2`：功率谱密度，单位为 信号单位²/Hz。
- 互谱实部/虚部：同为 信号单位²/Hz。
- 相干：无量纲，0–1。
- 相位：弧度。

## 输出

### 频谱 CSV

列：`frequency_hz, psd_ch1, psd_ch2, cross_real, cross_imag,
coherence, phase_rad`，共 `nfft/2 + 1` 个频点。

### 诊断 JSON

- `segments`：候选段数、实际使用段数、因缺测跳过的段数及其起始样本
  序号。
- `energy_check`：谱积分（双边谱积分乘回窗平方和 `Σw²`）与分段加窗
  时间域能量均值的一致性核对；`relative_difference < 1e-9` 视为一致。
- `window_power`：窗平方和 `Σw²`，即归一化所用的窗功率。

## 缺测窗口对结果的影响

- 缺测以**整段跳过**处理：段数减少，Welch 平均的自由度下降，谱估计
  方差增大（约与有效段数成反比），频谱曲线更粗糙。
- 不拼接缺口两侧数据，因此缺测**不会引入虚假频率成分或相位跳变**；
  代价是丢弃了缺口附近本可利用的样本。
- 若缺测集中在某些频段对应的时间段（如间歇性干扰），有效段集合可能
  不再代表全部数据，结果存在选择偏差；诊断 JSON 中的
  `skipped_missing_starts` 可用于核查被丢弃段的位置分布。
- 全部段均含缺测（或记录不足一整段）时工具明确失败，不输出任何谱。
