Pseudorange Position Lab
========================

离线教学解算器：从**已修正**的卫星位置与伪距出发，用纯 Python 标准库
估计接收机三维坐标与接收机钟差，并做观测敏感性（留一法）分析。
本工具不接收、不处理任何真实导航信号，仅面向教学数据。

观测模型
--------

对每颗卫星 `i`：

```
predicted_i = |sat_i - receiver| + clock        （单位：米）
weight_i    = 1 / sigma_i^2
```

四个未知量 `(x, y, z, clock)` 通过加权迭代最小二乘（Gauss-Newton）
**联合**估计；钟差不会被先固定为零再求坐标。协方差取最终加权法
矩阵 `(AᵀWA)⁻¹` 的逆，**不再**乘估计方差；CSV 中的原始标准差不会
被自动放大来掩盖异常。

输入格式
--------

观测 CSV（带表头，每行一颗卫星，长度均为米，数值必须有限）：

```
epoch,sat_id,x_m,y_m,z_m,pseudorange_m,sigma_m
e1,G01,20000000,0,15000000,22000000,1.0
```

约束：同一历元内 `sat_id` 唯一且至少 4 颗卫星；伪距与标准差均为正。

初值 JSON（每个历元独立给出，钟差以米表示）：

```json
{"epochs": {"e1": {"position_m": [6378000.0, 0.0, 0.0], "clock_m": 0.0}}}
```
```json
{"epochs": {"e1": {"position_m": [6378000.0, 0.0, 0.0], "clock_m": 0.0}}}
```

使用方法
--------

```
python -m pseudorange_lab examples/observations.csv examples/initial.json \
    --json-out report.json --csv-out report.csv
```

每个历元独立解算：某一历元失败（几何退化、初值落在卫星位置、
迭代不收敛）会以 `status: "error"` 明确记录，不会阻断其他历元，
也不会用补零增量冒充成功。退出码：全部成功为 0，有失败历元为 1，
输入文件非法为 2。

报告内容
--------

JSON 报告中每个成功历元包含：

- `position_m` / `clock_m`：估计的坐标与钟差；
- `residuals`：逐星残差（观测 − 预测，米）；
- `weighted_residual_sum_squares`：加权残差平方和 `Σ(r_i/σ_i)²`；
- `covariance`：4×4 协方差矩阵，即 `(AᵀWA)⁻¹`；
- `leave_one_out`（≥5 颗卫星时）：逐一剔除一颗后从**该历元原始
  初值**重解，报告解的位置/钟差变化与被剔除观测的外推残差。
  退化子集标记为 `"degenerate"`，不会把任何删星结果自动当成
  唯一正确答案。

CSV 报告为扁平表，含解、逐星残差与留一法结果三类行。

误差处理
--------

- `GeometryError`：线性化矩阵秩亏（几何退化）或迭代点落在卫星上；
- `ConvergenceError`：超过最大迭代次数或状态出现非有限值；
- `DataError`：输入缺列、重复标识、非正伪距/标准差、非有限数等。

模型假设与忽略项
----------------

本工具面向教学，**忽略**以下效应：电离层/对流层传播延迟、地球自转
（Sagnac 效应）、相对论修正、天线相位中心偏移、多路径与卫星轨道
误差。输入卫星位置与伪距视为已修正。残差与留一法分析用于课堂讨论
观测敏感性，不构成真实导航性能评估。

测试
----

```
python -m unittest discover -s tests
```

覆盖：已知位置恢复、共同钟差联合估计、加权行为、协方差、退化几何
报错、留一法（含退化子集标记与异常值检测）、输入校验与端到端
CLI（含历元失败隔离）。
