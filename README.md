# shaded-pv-string

光伏组串最大功率点计算工具。当串联组件性能不一致（如部分遮挡）时，
在完整电流范围内寻找**全局**最大功率点，并报告哪些组件已被旁路二极管钳位。

> **模型说明**：这是一个简化的分段线性模型，用于定性分析失配与旁路行为，
> 并非真实器件的精确预测。不模拟逆变器 MPPT、温度变化或二极管正向特性细节。

## 模型

每块组件的 I-V 曲线由两条直线定义：

- 开路点 `(0, Voc)` 到折点 `(Ik, Vk)`
- 折点 `(Ik, Vk)` 到短路点 `(Isc, 0)`

折点电压、电流都必须严格位于 0 与对应极限之间。电流超过 `Isc` 后沿第二段
直线继续外推，组件电压最低钳位到 `-Vd`（`Vd` 为旁路二极管压降，正值）。
电流达到钳位点即视为被旁路（恰到钳位值也算旁路）。弱组件不会被移除，
组串电流也不会被限制在最小短路电流。

串联时各组件电流相同，总电压为各组件电压之和。只在电流非负且总电压非负
的范围内计算发电功率。

## 寻优方法

最优点不是扫描网格的最高点，而是精确求得的：

1. 汇总全部组件的折点电流与旁路切换电流，加上组串零电压穿越点，
   把发电区间划分为若干线性段。
2. 每段上功率是电流的二次函数，检查其内部极值。
3. 比较所有内部极值与段端点，取功率最大者；多个峰等高时取较小电流。

因此 CSV 扫描步长（`step`）只影响扫描输出，不影响最优结果。

## 用法

```bash
python -m pv_string input.json -o report.json --csv scan.csv
```

输入 JSON（见 `examples/string.json`）：

- `diode_drop`：旁路二极管压降（V，正值）
- `step`：CSV 电流扫描步长（A）
- `modules`：默认组件列表，定义组串顺序
- `conditions`：多个工况；每个工况可给出自己的 `modules`（保持同一组件顺序），
  省略则使用默认列表

输出：

- 峰值报告 JSON：每个工况的最优点（电流、总电压、功率、逐组件电压与旁路状态）、
  局部峰列表、发电区间最大电流
- 电流扫描 CSV：每个工况逐电流的各组件电压、总电压与功率

