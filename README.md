# seatdesk：小型影厅连座分配工具

仅用 Go 标准库实现。按 JSONL 从标准输入接收操作、逐行向标准输出返回 JSON，
影厅与订单状态持久化在指定目录（`state.json`，原子写入），正常重开后结果一致。

## 运行

```sh
go run ./cmd/seatdesk -dir <状态目录>
```

## 操作协议（每行一个 JSON 对象）

```json
{"op":"init","rows":2,"cols":10,"disabled":[{"row":1,"col":3}]}
{"op":"alloc","orders":[{"id":"A","size":3,"row":1,"col":4}]}
{"op":"reseat","id":"A","size":2,"row":1,"col":5}
{"op":"release","id":"A"}
{"op":"query"}
```

- `init`：初始化影厅。座位总数 `rows*cols` 须为 1..20，`disabled` 列出停用坐标。
- `alloc`：一批至多 6 单同时分配，原子生效；整批无解或编号冲突（批内重复或
  与已有订单重复）则全部拒绝，不留下部分占座。
- `reseat`：整单换座，可修改人数与首选坐标，允许复用自己的原座，其他订单不动；
  先求出新分配再一次替换，失败时原订单内容与占座保持不变。
- `release`：释放整单占座，释放后的座位立即可再分配，不再计入占用。
- `query`：返回影厅配置、每笔订单的代价与座位、以及座位到订单编号的占用映射。

## 分配规则

- 每单必须分到**同排、列号连续**的可用座位；缺失或停用位置不能被跨过。
- 代价 = 单内每人所分座位到本单首选坐标的曼哈顿距离之和。
- 一批订单在**整批总代价最小**的可行方案中选择（回溯搜索 + 分支限界，
  不是逐单贪心）；同代价时按订单编号字典序排列、单内座位按坐标升序，
  取拼接坐标序列字典序最小者。
- 每个座位只能属于一单。

## 规模与性能

影厅至多 20 个座位，一批至多 6 单。每单候选方案数为 O(座位数)，
回溯枚举的最坏规模约为候选数的订单数次幂，在该规模上限下可瞬间完成；
搜索按当前代价做分支限界剪枝。

## 自定义分配规则

分配逻辑集中在 `internal/seatdesk/alloc.go`：

- 代价函数：修改 `costOf`（例如改为行优先加权、欧氏距离等）。
- 平局裁决：修改 `flatten`/`lessSeq` 的比较规则。
- 候选生成：修改 `candidates`（例如允许跨排、或加入座位等级过滤）。

改动后用 `go test ./...` 验证，`alloc_test.go` 覆盖了全局优于贪心、
平局裁决、换座失败保持原座、批次原子拒绝与持久化往返等场景。
