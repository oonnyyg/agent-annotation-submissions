# budgeted-stock-policy

一次性销售活动的备货决策工具：在共享采购预算下，为多个商品求**全局最优**
订货组合，并把每个商品的期望收益拆解为销售收入、残值回收、采购成本与
缺货损失，便于判断收益究竟来自真实销售，还是来自承担缺货 / 滞销风险。

仅使用 Python 标准库（3.12+），不调用任何在线服务或优化库。

## 用法

```bash
python -m stock_policy input.json --json-out plan.json --csv-out items.csv
```

- 省略 `--json-out` 时，方案 JSON 打印到标准输出。
- 省略 `--csv-out` 时，不生成逐商品 CSV。
- 输入非法时以退出码 2 报错，且不会生成任何部分输出文件。

## 输入格式

```json
{
  "items": [
    {
      "id": "a",
      "price_cents": 1000,
      "cost_cents": 600,
      "salvage_cents": 100,
      "shortage_penalty_cents": 50,
      "demand": {"0": "0.2", "1": "0.5", "2": "0.3"}
    }
  ],
  "budgets": [{"name": "tight", "budget_cents": 0}, {"name": "loose", "budget_cents": 1200}]
}
```

约束（全部在求解前校验，任一违反即整体失败）：

- 需求是非负整数的离散分布；概率必须是十进制字符串且总和严格等于 1。
  `demand` 也接受 `[{"quantity": 1, "probability": "0.5"}, ...]` 列表形式，
  相同需求量会被合并（概率相加）。
- 价格与成本使用整数分；`cost_cents > 0`，`price_cents >= cost_cents`，
  `0 <= salvage_cents <= cost_cents`，`shortage_penalty_cents >= 0`。
- `budgets` 中每个方案独立求解；可以直接写整数（`"budgets": [600]`）。

## 模型与收益拆解

对每个商品、每个 0 到需求上限的整数备货量 q，按完整需求分布（不以均值
代替）精确计算：

- 期望销量 `E[min(q, D)]`，按售价计销售收入；
- 期望剩余 `E[max(q - D, 0)]`，按残值回收；
- 期望缺货 `E[max(D - q, 0)]`，按缺货损失计罚；
- 期望收益 = 销售收入 + 残值回收 − 全部采购成本 − 缺货损失。

CSV 逐商品逐预算输出以上各项。例如某商品残值接近成本时，超备部分的
收益其实来自残值回收而非销售；缺货损失为 0 时少备货也没有惩罚——
拆解列让这些风险来源一目了然。

## 全局最优与并列规则

多商品共享预算，用多选背包动态规划求总期望收益最大的组合，不做
逐件收益率贪心（测试中包含贪心失效用例）。概率与期望收益全程使用
`Decimal` 精确计算，不提前四舍五入，因此不会因舍入改变最优组合。
输入商品顺序不影响结果（内部按商品编号排序）。

收益并列时依次：

1. 取总采购成本更小（资金占用更少）者；
2. 取按商品编号排序的数量向量字典序较小者。

## 问题规模限制

- 单商品备货量只需枚举 0..最大需求（超过最大需求的备货被严格支配，
  自动裁剪）。
- DP 状态数为预算内可达的不同总采购成本个数；时间约为
  状态数 × 每商品备货档数 的乘积级别。预算（分）很大且成本互质时
  状态数会接近预算本身，更大规模请先换算预算单位或分批求解。
- 所有计算精确、无浮点误差，代价是大数 Decimal 略慢于浮点。
