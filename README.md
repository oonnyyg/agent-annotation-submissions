# duplex-print-spool

共享打印室的本地打印作业工具（纯 Go 标准库）。把文档选页范围转换成逐纸
正/反面的用纸计划，按单台打印机顺序调度，用 JSONL 命令交互；打印动作由
确认命令模拟，不连接真实设备。状态本地持久化，重启后自动续接。

## 运行

```sh
go run . -state spool_state.json
```

从标准输入逐行读入 JSON 命令，每行输出一条 JSON 响应。`-state` 指定持久化
文件（默认 `spool_state.json`），每条命令处理后落盘，杀掉进程重启即可续打。

## 命令

### 登记用户

```json
{"cmd":"register_user","user":"alice","quota":100}
```

`quota` 为该用户的纸张总额度（张）。

### 提交作业

```json
{"cmd":"submit","user":"alice","doc":"report","total_pages":9,"ranges":"1-3,2,7","copies":2,"duplex":true}
```

- `ranges`：逗号分隔的页码或区间（如 `1-3,5,8-7`）。重叠部分只保留一次，
  结果按原文页码升序；任何非法或越界范围整单拒绝。
- `duplex:true` 双面（每张纸正面+背面），`false` 单面（只用正面）。
- 逐份编排，每份都从正面开始；奇数末页的背面留空。
- 提交时一次性预留整个计划所需纸张；额度不足整单拒绝、不入队。
- 响应：`{"ok":true,"job":"job-1","sheets":4,"pages":[1,2,3,7]}`。

### 暂挂 / 恢复

```json
{"cmd":"pause","job":"job-1"}
{"cmd":"resume","job":"job-1"}
```

只有尚未开始打印的作业可以暂挂；暂挂项不阻塞后续待打印项。

### 确认打印（模拟出纸）

```json
{"cmd":"confirm","job":"job-1","sheet":1}
```

- 每次确认当前活动作业的下一张纸，同时把 1 张预留转为实际消耗。
- 重复确认已打印的纸、跳过未确认的纸、确认非活动/已结束作业都会被拒绝，
  且不会改变队列或额度。
- 中断后进度保留，恢复后从下一张继续，不重印已确认内容。

### 取消作业

```json
{"cmd":"cancel","job":"job-1"}
```

只释放尚未打印的预留纸张；已消耗纸张与历史记录保留。已结束（完成/已取消）
的作业不能再确认或取消。

### 查询

```json
{"cmd":"plan","job":"job-1"}        // 逐纸正/反面计划及已打印标记
{"cmd":"status"}                    // 队列状态与当前活动作业
{"cmd":"report","user":"alice"}     // quota / reserved / used / remaining
```

## 纸张核算规则

- `reserved`：未完成作业占用的预留纸张；`used`：已确认消耗的纸张。
- 可用额度 = `quota - reserved - used`，提交时校验。
- 确认一张：`reserved-1, used+1`；取消：释放该作业剩余全部 `reserved`。

## 测试

```sh
go test ./...
```

覆盖：范围重叠去重与排序、非法范围整单拒绝、奇数页背面留空、多份逐份
编排、额度预留与不足拒绝、确认顺序/重复/跳张校验、暂挂不阻塞队列、
持久化重启续打、中断后取消的纸张核算、非法操作不改变状态。
