# elastic_modes — 各向异性弹性波模态计算工具

纯 Python 标准库实现，比较不同传播方向的弹性波速，并区分**真实各向异性**
（由弹性张量本身决定）与**坐标选择造成的表面差异**（取向旋转不改变物理，
波速与偏振子空间在相应旋转的方向下保持不变）。

## 用法

```
python -m elastic_modes config.json [--velocities out.csv] [--diagnostics diag.json]
```

配置示例见 `examples/config.json`：

```json
{
  "material": {"density": 2700.0, "stiffness": [[...6x6...]]},
  "orientation": [[1,0,0],[0,1,0],[0,0,1]],
  "directions": [[1,0,0],[0,0,1],[1,1,1]],
  "degeneracy_rtol": 1e-6
}
```

`material` 内的键也可以平铺在顶层。支持同一材料的批量方向计算。

## 张量约定

- **刚度**：单位 Pa，6x6 Voigt 矩阵，**工程剪应变**约定，分量顺序
  `11, 22, 33, 23, 13, 12`。必须对称正定（Cholesky 检验），否则整次计算被拒绝。
- **密度**：kg/m³，必须为正的有限数。
- **取向矩阵 Q**：列为晶体轴在实验室坐标中的方向，即 `v_lab = Q @ v_crystal`。
  必须正交且行列式为 +1（真旋转）。缺省为单位矩阵。
- **Christoffel 矩阵**：`Γ_ik = C_ijkl n_j n_l`，由实验室坐标下的完整四阶弹性
  张量构建（Voigt → 全张量 → 旋转 → 收缩），**不是**只取刚度矩阵对角元。
- 每个传播方向先归一化；对 Γ 用 Jacobi 扫掠法求三个本征模态，
  波速 `v = sqrt(λ/ρ)`。本征值显著为负时整次计算报错，
  **不会**取绝对值冒充实数波速。不计算群速度与传播衰减。

## 输出

**波速 CSV**（默认 `velocities.csv`）：每方向 3 行，按波速升序，
列为方向索引、归一化方向、模态号、波速、简并组号、简并维数、偏振分量。

**模态诊断 JSON**（默认 `diagnostics.json`）：每方向给出

- 每个模态的本征值、波速、本征残差 `‖Γv − λv‖∞`；
- 非简并模态的实验室坐标单位偏振向量（绝对值最大分量取正，同大按坐标顺序）；
- 简并组的维数与投影矩阵 `P = Σ v vᵀ`（不强行指定唯一偏振方向）；
- 三个偏振向量两两正交误差的最大值。

## 简并容差

以该方向最大本征值 `λ_max` 为尺度，相邻（升序）本征值之差满足
`λ_{k+1} − λ_k ≤ degeneracy_rtol × λ_max` 时连为同一简并组（链式合并）。
默认 `1e-6`，可在配置中用 `degeneracy_rtol` 覆盖。

## 输入校验

任何非法输入（非对称/非正定刚度、非正密度、非正交或行列式非 +1 的取向、
零方向、非有限数值、负 Christoffel 本征值）都会以退出码 2 拒绝**整次**计算，
不输出部分结果。

## 测试

```
python -m unittest discover -s tests
```

覆盖：各向同性双重横波简并（简并维数 2、投影矩阵湮灭纵波方向）、
旋转晶体与反向旋转方向的波速等价性、投影结构旋转不变性、各类非法输入拒绝。
