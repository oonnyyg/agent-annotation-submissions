# Parallel-Beam Reconstruction

纯标准库实现的平行束滤波反投影（FBP）工具，用于把**本地合成投影数据**
重建为二维数值矩阵，验证 FBP 流程。不用于临床影像。

## 用法

```bash
# 生成圆盘解析投影（合成验证数据）
python -m pbr make-disk --config geom.json --output sino.csv \
    --angles 60 --radius 10 --attenuation 2.5 [--center-x 0 --center-y 0]

# 重建
python -m pbr reconstruct --projections sino.csv --config geom.json \
    --output image.csv --summary summary.json
```

## 输入格式

**几何配置 JSON**：

```json
{
  "detector_count": 33,
  "detector_spacing": 1.0,
  "image": {"nx": 33, "ny": 33, "dx": 1.0, "dy": 1.0}
}
```

**投影 CSV**：每行 `angle_deg, d0, d1, ..., d{n-1}`，读数个数必须等于
`detector_count`。角度必须均匀覆盖 `[0, 180)` 度（步长 `180/N`，不含右端
点），缺行、重复角度或越界角度都会被拒绝。

## 几何约定

探测器与图像均以几何中心为原点：探测器 `i` 位于
`(i - (n-1)/2) * spacing`，像素 `(ix, iy)` 位于
`((ix - (nx-1)/2) * dx, (iy - (ny-1)/2) * dy)`。偶数网格**不**偏移半格，
中心落在两个采样点之间（如 4 点网格坐标为 `-1.5, -0.5, 0.5, 1.5`）。

## 傅里叶约定

- 频率以**每单位长度的周数**（cycles per unit length）表示，不使用角频率。
- 每条投影先零填充到 `>= 2 * detector_count` 的最小 2 的幂长度 `L`，
  再做离散傅里叶变换。
- 滤波乘子为 `|f|`，其中 bin `k` 的频率为 `k / (L * spacing)`（负半部分
  按常规回绕）。
- 逆变换（含 `1/L` 归一化）后裁回原探测器位置。由于
  `s * DFT` 近似连续傅里叶变换、频率采样间隔为 `1 / (L s)`，该结果直接
  近似连续滤波投影 `∫ |f| P(f) e^{2πift} df`，**不做**任何额外的最大值
  归一化或重缩放。

## 反投影

像素中心 `(x, y)` 投影到探测器坐标 `t = x cosθ + y sinθ`，对滤波后的
投影做线性插值，超出探测器范围按零处理。各角度贡献相加后乘以弧度角间隔
`π / N`。负值保留，不裁剪为零。

## 输出

- 重建矩阵 CSV：行对应 `y`（从负到正），列对应 `x`。
- 摘要 JSON：坐标范围、采样间距、角度配置、滤波配置及结果统计。

## 限制

最多 64 个角度、64 个探测器、64×64 图像，超限会明确报错（退出码 2）。

## 离散误差说明

- 斜坡滤波放大高频，探测器采样有限会引入混叠与吉布斯振荡，圆盘边缘
  附近出现过冲/欠冲（负值）属正常现象。
- 零填充可缓解循环卷积的环绕伪影，但截断信号仍会造成频谱泄漏。
- 角度采样离散化导致径向条纹伪影，角度数越多越弱。
- 线性插值反投影会轻微平滑图像。
- 综合上述因素，圆盘中心重建值与解析衰减值的误差通常在百分之几以内
  （测试取 15% 容差）。

## 测试

```bash
python -m unittest discover -s tests
```

测试覆盖：圆盘解析投影的幅值尺度与对比方向、中心对称性、偏心圆盘位置、
负值保留、斜坡滤波器尺度约定、角度校验（缺行/重复/端点/均匀性）以及
偶数网格不偏移半格的几何约定。
