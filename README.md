# 回热布雷顿循环教学核算器

纯 Python 标准库实现的教学工具，用于比较不同压比对回热布雷顿循环
净功与热效率的影响。**仅用于热力学教学演示，不构成任何实际发动机
设计建议。**

## 使用方法

```sh
python brayton.py examples/config.json examples/cases.csv
python -m unittest test_brayton.py   # 运行测试
```

- JSON 文件给出循环固定参数（见 `examples/config.json`）。
- CSV 文件列出各工况压比，列名为 `pressure_ratio`，压比互不重复且大于一。

## 输入参数

| JSON 字段 | 含义 | 约束 |
| --- | --- | --- |
| `compressor_inlet_temp` | 压缩机入口温度 T1 (K) | 正的有限值 |
| `turbine_inlet_temp` | 涡轮入口温度 T3 (K) | 高于 T1 |
| `specific_heat_cp` | 定压比热 cp (kJ/(kg·K)) | 正常数 |
| `heat_capacity_ratio` | 比热比 γ | 大于 1 |
| `compressor_efficiency` | 压缩机等熵效率 | (0, 1] |
| `turbine_efficiency` | 涡轮等熵效率 | (0, 1] |
| `regenerator_effectiveness` | 回热器有效度 | [0, 1] |

所有数值必须为有限值，非法输入会以错误信息拒绝。

## 模型假设

- 工质为理想气体，cp 与 γ 为常数；两股流体质量流量相同。
- 忽略所有压降，涡轮膨胀比等于压缩比，各工况相互独立。
- 先由等熵关系求理想出口温度：`T2s = T1·r^((γ-1)/γ)`，
  `T4s = T3·r^(-(γ-1)/γ)`。
- 压缩机效率作用于温升的分母：`T2 = T1 + (T2s - T1)/ηc`；
  涡轮效率作用于理想温降：`T4 = T3 - ηt·(T3 - T4s)`。两者修正
  方式不同，不可互换。
- 仅当 `T4 > T2`（涡轮排气比压缩机出口热）时回热：
  `q_regen = ε·cp·(T4 - T2)`；否则回热器旁路，回热量为零，不会
  把冷排气强行用于加热。
- 外部吸热 `q_in = cp·(T3 - T2')`，外部排热 `q_out = cp·(T4' - T1)`，
  其中 T2'、T4' 为回热器出口两侧温度；净功 `w_net = w_t - w_c`，
  并核对 `w_net = q_in - q_out`。

## 输出与判据

每个工况输出各状态温度（含理想等熵温度）、单位质量压缩功、涡轮功、
净功、回热量、外部吸热与排热、热效率及能量核对结果。外部吸热非正
或净功非正的工况标记为“不可用”，但其诊断信息仍保留。最后在可用
工况中分别选出净功最大与热效率最高的方案，同值时取较小压比；若没
有任何可用方案则明确报告。

## 测试

`test_brayton.py` 覆盖：理想极限（效率与有效度均为 1 时实际温度
等于等熵温度）、两种效率作用于不同项、回热旁路、回热量公式、不可
用工况诊断、能量平衡核对与优选规则。
