# Gaussian Plume Exposure（离线多源扩散核算工具）

基于平地稳态高斯烟羽（含地面镜像反射）的离线多排放源暴露核算工具。
仅使用 Python 标准库，针对**一种**惰性或一阶衰减物质，逐气象时段计算
各污染源对每个受体的浓度贡献，并按有效时长加权汇总。

> 本工具输出为筛查级估算，**不构成任何合规判定**。

## 运行

```bash
python -m plume_exposure config.json met.csv --out-dir out
```

输出：

- `out/contributions.csv`：逐时段 × 源 × 受体的浓度与时间积分明细。
- `out/summary.json`：各受体的时长加权平均浓度、浓度时间积分、
  峰值浓度及所属时段（并列取最早时段）。

## 输入

### 配置 JSON

```json
{
  "pollutant": {"name": "SO2", "decay_rate": 0.0},
  "sources": [
    {"id": "A", "easting": 0, "northing": 0, "height": 20, "emission_rate": 2.0}
  ],
  "receptors": [
    {"id": "R1", "easting": 0, "northing": -500, "height": 0}
  ],
  "dispersion": {
    "sigma_y_coeff": 0.5, "sigma_y_exp": 0.8,
    "sigma_z_coeff": 0.4, "sigma_z_exp": 0.8
  }
}
```

### 气象 CSV

```csv
start,end,wind_speed,wind_dir
2026-01-01T00:00,2026-01-01T01:00,5,0
2026-01-01T02:00,2026-01-01T04:00,8,45
```

时段为左闭右开区间 `[start, end)`，允许间隔，禁止重叠。任一行非法
（重叠、风速非正、时间倒置等）将拒绝整次计算，退出码为 2。

## 单位约定

| 量 | 单位 |
| --- | --- |
| 坐标（东向/北向）、源高、受体高 | m |
| 排放率 | 质量/s（如 g/s） |
| 风速 | m/s |
| 衰减率 | 1/s |
| 风向 | 度，从正北顺时针的**来向**角 |
| 浓度 | 质量/m³（与排放率质量单位一致） |
| 时间积分 | 浓度·s |

扩散宽度按幂律 `sigma = coeff * x^exp`（x 为下风距离，米），系数与
指数均须为正。

## 模型说明与局限

- 每个气象时段独立视为稳态，各源浓度线性叠加；时段间不做平流衔接。
- 地面完全反射（镜像源），不计算烟羽抬升、地形、建筑物下洗或
  湿/干沉降；一阶衰减仅按下风输送时间 `x/u` 施加。
- 下风距离非正（受体位于上风向）时贡献为零。
- 平均浓度按有效时段时长加权，时段间隔不计为零浓度时段。
- **近源局限**：稳态高斯烟羽在下风距离趋近于零时扩散宽度趋近于零、
  浓度趋于发散，模型在源附近（约数十米内，取决于扩散参数）不具物理
  意义；请勿将近源结果用于暴露评估结论。
- 静风（风速为零）不属于本模型适用范围，输入静风时段会被拒绝而非
  以零浓度替代。
