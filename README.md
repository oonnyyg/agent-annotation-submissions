# elastic_modes — 各向异性弹性波模态计算工具

仅用 Python 标准库实现。读取材料刚度、密度与晶体取向，对一批传播方向求解
Christoffel 方程，输出三个体波模态的波速（CSV）与模态诊断（JSON）。
不计算群速度，不计算传播衰减。

## 用法

```
python -m elastic_modes config.json --csv velocities.csv --json diagnostics.json
python -m unittest discover -s tests
```

配置示例见 `examples/isotropic.json` 与 `examples/rotated_cubic.json`。

## 输入约定

- `density`：质量密度，正数（kg/m³）。
- `stiffness`：6×6 刚度矩阵，单位 Pa，Voigt 顺序为 **11, 22, 33, 23, 13, 12**，
  剪应变采用工程剪应变约定。矩阵必须对称正定（Cholesky 检验），否则整次计算被拒绝。
- `orientation`（可选，默认单位阵）：3×3 矩阵，**列**为晶体轴在实验室坐标中的
  方向。必须正交且行列式为 +1（真转动）。
- `directions`：非空传播方向列表。每个方向先归一化；零向量被拒绝。
- `degeneracy_rel_tol`（可选，默认 1e-6）：简并判据的相对容差。

任何非法输入都会以非零退出码拒绝**整次**计算，不写部分结果。

## 计算方法

1. 将 Voigt 刚度展开为完整四阶张量 `c_ijkl`（Voigt 刚度到张量的映射不含
   工程剪应变的因子 2，因子 2 只出现在应变侧）。
2. 方向经取向矩阵转入晶体坐标系：`n_xtal = Qᵀ n_lab`。
3. 建立 Christoffel 矩阵 `Γ_ik = c_ijkl n_j n_l`（使用完整张量，**不是**
   只取刚度对角元），用循环 Jacobi 法求本征对。
4. 偏振向量转回实验室坐标：`p_lab = Q p_xtal`。波速与偏振子空间因此对
   坐标系选择保持不变——旋转晶体同时旋转方向，结果完全一致；各向同性
   材料在任意取向下结果相同（见测试）。若固定实验室方向只旋转晶体，
   波速变化是**真实各向异性**，而非坐标假象。
5. 波速 `v = sqrt(λ/ρ)`。若出现非正本征值（物理上不可能，除非输入有
   误），直接报错，**绝不**取绝对值冒充实波速。

## 输出

CSV 每行一个模态，按波速升序：方向、模态序号、简并度、波速、本征值、
偏振向量（实验室坐标单位向量，绝对值最大的分量取正，并列时按坐标顺序
取先）与归一化本征残差 `‖Γp − λp‖ / λ_max`。

诊断 JSON 额外包含：

- 简并组：相邻本征值差 ≤ `rel_tol × λ_max` 时连为一组。简并组只给出
  维数与子空间**投影矩阵** `P = Σ pᵢpᵢᵀ`，不强行指定唯一偏振方向。
- `orthogonality_error`：三个偏振向量两两内积与单位阵的最大偏差。

## 容差说明

- 简并判定：`rel_tol`（默认 1e-6）乘以最大本征值。各向同性材料的两个
  横波在任意方向都严格简并，会被识别为二维简并组。
- 刚度对称性检验：相对容差 1e-9。
- 取向正交性与行列式检验：绝对容差 1e-6。
