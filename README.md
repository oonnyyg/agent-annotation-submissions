# Group Seat Allocation (seatdesk)

小型影厅连座分配工具。通过 JSONL（每行一个 JSON 操作）与标准输入/输出交互，
状态持久化在指定目录，重启后结果一致。

## 运行

```sh
go run ./cmd/seatdesk -dir ./seatdesk-data
```

`-dir` 指定状态目录（默认环境变量 `SEATDESK_DIR`，否则 `./seatdesk-data`）。
状态写入 `<dir>/state.json`（先写临时文件再原子重命名）。

## 操作协议

每行一个请求，每行返回一个响应（`{"ok":true,...}` 或 `{"ok":false,"error":...}`）：

- `{"op":"create","rows":2,"cols":5}` 创建影厅（`rows*cols <= 20`）。
- `{"op":"disable","seats":[{"row":1,"col":3}]}` / `{"op":"enable",...}` 停用/恢复座位；
  已占用座位不能停用。
- `{"op":"book","orders":[{"id":"A","size":2,"pref":{"row":1,"col":3}},...]}`
  一批 1–6 单同时分配。整批不可行或编号冲突（批内或与已有订单）时全部拒绝，
  不留下部分占座。
- `{"op":"change","id":"A","size":3,"pref":{"row":2,"col":1}}` 整单换座，可修改人数
  与首选坐标，允许复用自己的原座；其他订单不动。先完整求出新分配再一次性替换，
  失败时原订单内容与占座保持不变。
- `{"op":"release","id":"A"}` 释放整单，座位立即可被后续订单使用。
- `{"op":"query"}` 返回所有订单（含每单代价与座位归属）、占用映射与停用座位；
  已释放座位不再计为占用。

## 分配规则

- 每单必须分到**同排、列号连续**的可用座位段；停用或缺失位置不能被跨过
  （停用座位会把座位段切开）。
- 代价 = 单内各座位到本单首选坐标的曼哈顿距离之和。
- 一批订单选择**整批总代价最小**的可行方案（DFS 枚举每单的候选座位段 +
  位占用剪枝），不是逐单贪心。
- 总代价相同时：订单按编号字典序排列，每单座位按坐标升序，取拼接坐标序列
  字典序最小者。
- 换座（`change`）等价于规模为 1 的批分配，但把自己的原座视为可用。

## 规模与复杂度

- 影厅最多 20 个座位，一批最多 6 单。
- 每单候选座位段数 ≤ 20（全厅座位数上限），DFS 搜索上界约 20^6 且被占用
  剪枝大幅收缩，实际毫秒级完成。

## 自定义分配规则

核心逻辑在 `internal/hall`：

- 改代价函数：修改 `seatCost`（如加权距离、按排加价）。
- 改平局规则：修改 `compareRuns` / `compareChoice`。
- 改候选生成（如允许跨排、最大段长）：修改 `candidates`。
- 改批规模上限：修改 `MaxBatch`。
