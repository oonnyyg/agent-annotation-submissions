# Series Bar Cyclic Plasticity

一维串联杆件循环加载分析工具，仅使用 Python 标准库（不依赖任何有限元或数值计算库）。

## 模型

- 小应变一维杆件，左端（节点 0）固定，右端施加指定位移历程。
- 各段可有不同的长度、截面积和材料参数；段间通过轴力连续（不是应力连续）耦合。
- 材料：线性各向同性硬化。屈服强度 `sigma_y = sigma_y0 + H * alpha`，
  其中 `alpha` 为累计塑性应变（只增不减），拉压对称。
- 每段保存有符号塑性应变 `eps_p` 和累计塑性应变 `alpha`。
- 不考虑惯性、温度；初始状态无应力。

## 求解

每个加载步用 Newton 迭代联立求解：

- 内部节点平衡：相邻两段轴力相等（`A_i * sigma_i = A_{i+1} * sigma_{i+1}`）；
- 位移兼容：各段伸长之和等于规定端位移。

材料层面采用弹性预测 + 返回映射，切线取一致切线 `E_t = E*H/(E+H)`，
组集为三对角 Jacobian，用 Thomas 算法求解，并带步长减半的阻尼线搜索。
所有试算均从上一收敛步的历史变量出发；只有全局残差满足容差后才提交整步历史。
达到迭代上限时该步标记为失败，保留此前已收敛的结果，绝不把失败步补成零值。

## 收敛判据

- 力残差：内部节点轴力不平衡量的最大绝对值 `<= tol_force`（默认 1e-8，力单位）；
- 位移修正：Newton 修正量最大绝对值 `<= tol_disp`（默认 1e-12，长度单位），
  且修正后需重新验证力残差；
- 最大迭代次数默认 50。

## 单位

单位自洽即可（例如 mm-N-MPa 或 m-N-Pa）。长度、位移同单位；
弹性模量、屈服强度、硬化模量与应力同单位；反力 = 应力 x 面积。

## 输入

结构 JSON（`examples/config.json`）：

```json
{
  "elements": [
    {"length": 100.0, "area": 10.0,
     "youngs_modulus": 200000.0, "yield_strength": 250.0,
     "hardening_modulus": 10000.0}
  ]
}
```

位移历程 CSV（`examples/displacements.csv`）：每行一个按序施加的端部位移，
首行可为表头。所有数值必须有限；长度、面积、模量、屈服强度、硬化模量必须为正，
非法输入会被拒绝并以非零码退出。

## 用法

```sh
python -m series_bar.cli CONFIG.json DISPLACEMENTS.csv \
    --results results.csv --diagnostics diagnostics.json \
    --tol-force 1e-8 --tol-disp 1e-12 --max-iter 50
```

退出码：0 全部收敛；1 某步不收敛（此前收敛步仍写出）；2 输入非法。

## 输出

- 结果 CSV：逐步的反力、各节点位移、各段应变/应力/轴力/有符号塑性应变/
  累计塑性应变，以及每步的轴力不平衡量和位移兼容残差。
- 诊断 JSON：收敛状态、失败步编号、容差、每步迭代数、反力、
  轴力不平衡、位移兼容残差、最大塑性应变。

真实残余变形体现在收敛历史中的有符号 `eps_p`（卸载后非零、卸载反向可演化）；
求解误差体现在 `force_imbalance` 与 `compatibility_residual` 两列，
收敛步中它们应处于容差量级。

## 测试

```sh
python -m unittest discover -s tests
```

覆盖：纯弹性（不同截面的力/伸长分配）、先后屈服、反向加载
（卸载、反向屈服、累计量单调性）、非法输入拒绝、不收敛失败路径。
