# fractional-lot-cost-basis

本地合成交易记录的批次成本核对工具。按事件顺序回放单币种的买入、卖出与
拆并股，维护分数持仓的数量与成本对账。全程离线：不连接行情或交易平台。

本工具只做数量与成本的算术核对，输出**不构成任何税务结论**。

## 输入规则

输入为 JSONL 文件，每行一个事件，单币种，按时间顺序排列：

- `id`：全局唯一字符串；重复即拒绝。
- `time`：RFC3339 时间戳，不得倒退。
- `type`：`buy` / `sell` / `split`。
- 数量与拆并股比例：十进制或分数字符串，如 `"1.5"`、`"3/2"`，必须为正。
- 金额与费用：整数分（`total_cents`、`fee_cents`），非负。

事件字段：

| 类型   | 必填字段                                                     |
|--------|--------------------------------------------------------------|
| buy    | `quantity`, `total_cents`, `fee_cents`                       |
| sell   | `quantity`, `total_cents`, `fee_cents`, 可选 `method`/`allocations` |
| split  | `ratio`                                                      |

卖出 `method` 缺省为 `fifo`；`specific` 时需提供
`allocations: [{"lot": "<买入事件id>", "quantity": "..."}]`，
各分配之和必须精确等于卖出量。

## 计算规则

- 内部一律使用精确有理数（`math/big.Rat`），不使用浮点累计，不提前取整；
  输出为精确分数（分），保证金额可对账。
- 买入建立独立批次，成本 = `total_cents + fee_cents`。
- 卖出按批次数量比例消耗成本；净所得（`total_cents - fee_cents`）按本次
  各批次数量占比分摊，逐批计算已实现差额 = 分摊所得 − 消耗成本。
- 任何校验失败（持仓不足、分配不等、字段非法等）整体拒绝，绝不部分扣减；
  被拒绝的事件仍占用事件序号，但不改变状态，后续事件继续回放。
- 拆并股用正比例乘全部未关闭批次的剩余数量，总成本与买入次序不变；
  允许产生分数持仓，不处理零股现金结算；历史卖出与已实现差额不被改写。

## 命令行

```sh
go run . [-snapshot N] events.jsonl
```

- 默认输出每个事件的接受/拒绝结果、最终批次明细（数量、成本）及每笔卖出
  的来源成本与已实现差额。
- `-snapshot N`：输出第 N 号事件（含）之后的持仓快照；`-1` 为初始空状态。
  历史快照在独立账本上重放前缀，不污染后续回放。

## 测试

```sh
go test ./...
```

覆盖：部分卖出后拆股、指定批次不足的整体拒绝、FIFO 跨批次分摊、
精确分数对账、快照隔离与序号语义、重复 id 与时间倒退。

## 边界说明

- 仅支持单币种；多币种文件需按币种拆分后分别回放。
- 金额以整数分输入，内部不引入汇率或价格换算。
- 分数分母可任意大，内存随计算精度增长；极端长链回放可能变慢。
- 拒绝事件留痕于输出，便于定位数据问题后修正源文件重跑。
