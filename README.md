# MIDI 音符时间线分析器

离线 MIDI 分析工具（仅 Go 标准库）：把多音轨 MIDI 事件还原成真实时间上的
音符区间，输出 CSV 音符表与 JSON 异常汇总。不播放、不合成音频。

## 用法

```sh
go run ./cmd/midinotes <input.mid> [notes.csv] [anomalies.json]
go test ./...
```

## 支持范围

- 标准 MIDI 文件零型与一型；拒绝二型。
- 仅支持"每四分音符 tick 数"的正时基；拒绝 SMPTE 时基。
- 解析轨道块与变长整数（最长 4 字节），支持运行状态。
- 不处理的元事件与系统独占事件（SysEx 0xF0 / 转义 0xF7）按声明长度跳过。
- 文件截断、长度越界、变长整数过长等错误均带轨道号 / 事件序号 / 偏移定位。

## 事件与时间

- 所有轨道事件合并后按（绝对 tick、轨道原序号、轨内顺序）稳定排序。
- 默认速度为每四分音符 500000 微秒；所有轨道的速度元事件共同生效，
  同一 tick 多个速度事件时最后一个为后续速度。
- tick 到秒的换算按速度段分段积分。

## 音符还原规则

- 按（轨道、通道、音高）配对开启 / 关闭；同键多次开启按先进先出关闭；
  零力度开启视为关闭。
- 每个音符输出按键起止（on/off）与声音终点（end）三组 tick 与秒。
- 延音踏板（CC64，值 ≥ 64 为踩下）按（轨道、通道）独立处理：
  - 踩下时关闭音符只记抬键，松开踏板时才结束被延住的声音；
  - 延音期间重新开启同音高会生成新音符，不吞掉之前的延音。
- 异常（写入 JSON）：
  - `unmatched_note_off`：关闭没有匹配的开启；
  - `unclosed_note`：文件结束仍未关闭，截到全文件最大事件 tick 并标记
    （CSV 中 `truncated=true`）；未结束的踏板延音同样截到文件结束。

## 输出

- CSV 音符表：轨道、通道、音高、力度、按键起止与声音终点的 tick 和秒、
  踏板延音与截断标记。
- JSON 汇总：文件结束 tick / 秒、每轨道最大同时发声数、异常列表。
- 最大同时发声数按每轨道统计，使用左闭右开的声音区间
  `[on_sec, end_sec)`，零时长音符不计。

## 时间精度

秒数以 float64 存储，由 tick 经速度分段积分得到；CSV 中秒保留 6 位小数
（微秒级）。tick 为整数无精度损失。
