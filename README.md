# elfmap — 离线 ELF 装载审计工具

`elfmap` 在**不执行**目标程序的前提下，说明一个 ELF 文件的内容如何
映射到虚拟地址空间，并审计页权限与入口点。

```sh
go run ./cmd/elfmap [-config query.json] <elf-file>
```

输出为一份 JSON 报告（默认缩进），包含段映射、按 4096 字节合并的页
权限、可疑的可写且可执行（W^X 冲突）页、入口审计结果，以及配置中每个
读取查询的结果。

## 支持范围

- 仅支持小端 ELF64、`e_machine == EM_X86_64` 的 `ET_EXEC` 与 `ET_DYN`。
  其它类别、字节序、架构或类型一律拒绝。
- 只依据**程序头表**（program headers）构建映射，节表（section headers）
  完全不参与。
- 仅装载 `PT_LOAD`；其它类型的程序头被忽略。

## 校验规则

- 程序头表必须完整落在文件范围内（乘法与加法均做 64 位溢出检查）。
- `p_filesz <= p_memsz`；文件数据之后到 `p_memsz` 之间是补零区（BSS）。
  `memsz == 0` 的段不占用任何虚拟空间。
- 每个段的文件区间 `[p_offset, p_offset+p_filesz)` 必须落在文件内。
- `p_align` 只能是 0、1 或 2 的幂；当 `p_align > 1` 时要求
  `p_offset ≡ p_vaddr (mod p_align)`。
- 文件区间允许多个段重复使用；但**非空虚拟内存区间不允许重叠**。
- `ET_EXEC` 的装载偏移固定为 0；`ET_DYN` 使用配置中的 `load_bias`，且
  偏移必须满足每个段的非平凡对齐。
- 所有地址加法都检查 64 位溢出。

## 页权限与入口审计

- 相交于同一 4096 字节页的所有段，其权限取并集；相邻同权限页合并报告。
- `wx_pages` 列出同时具备写与执行权限的页（可疑页）。
- 非零 `e_entry`（加重定位偏移后）必须位于某个带 `PF_X` 的段的
  **文件数据**范围内；`e_entry == 0` 报告为“无入口”，否则报告无效入口。

## 读取查询

配置示例：

```json
{
  "load_bias": "0x555555554000",
  "reads": [
    {"name": "elfmagic", "addr": "0x555555554000", "length": 4}
  ]
}
```

- 单次读取最多 65536 字节；地址支持十六进制字符串或十进制数。
- 读取可跨越相邻段以及段尾的补零区；一旦触及未映射空洞，**整次读取
  失败**（不返回部分结果）。
- 结果以区间片段表示：`"data"` 片段携带 base64 文件字节，`"zero"` 片段
  只用 `start`/`end` 描述补零范围，因此巨大的 BSS 不会按虚拟空间大小
  分配内存。

## 明确不做的事

- **不执行**目标文件，也不进行动态链接、解释器装载或 `LD_PRELOAD` 等
  处理。
- 不处理重定位（REL/RELA）、动态符号、PLT/GOT 绑定；报告中的虚拟地址
  是“文件内容按程序头摆放”的静态结果，`ET_DYN` 仅整体加上配置偏移。
- 不修改目标文件：始终以只读方式打开。

## 测试

```sh
go test ./...
```

测试用内存中合成的最小 ELF64 镜像覆盖：跨相邻段与补零区读取、空洞失败、
共享页权限合并出 WX 页、偏移对齐、入口审计，以及各类损坏程序头（文件范围
越界、filesz>memsz、非法/非同余对齐、程序头表被截断等）。
