# Newick Distance Workbench

纯 Python 标准库工具：读取带枝长的单棵 Newick 树，按样本名剪枝，做中点定根，
并导出确定顺序的 Newick 树与 CSV 叶间距离矩阵。只做拓扑重组，**不重新推断进化关系**，
保留样本间的路径距离。

## 用法

```sh
python newick_workbench.py input.nwk --keep 样本A 样本B 样本C \
    --out-tree rooted.nwk --out-matrix dist.csv
```

- `input.nwk`：输入树文件（`-` 表示标准输入，自动容忍 UTF-8 BOM）。
- `--keep`：至少两个现有叶名；省略则保留全部叶。被压缩掉的内部标签会打印到
  stderr（`removed internal label: ...`），不会默默挪给别的节点。
- `--out-tree` / `--out-matrix`：省略时写到标准输出。

## 输入规则

- 单棵树，支持多分叉、单引号标签（`''` 表示字面单引号）、不嵌套的 `[...]` 注释。
- 每条非根边必须有有限、非负的长度；根枝长只能省略或为 0。
- 叶名非空且唯一；内部标签可选。不加引号的标签中 `_` 按 Newick 惯例转为空格。

## 处理流程

1. **解析与校验**：构造树并检查上述规则。
2. **剪枝**（可选）：删除未保留的分支；非根的一入一出节点被压缩且枝长相加；
   根只剩一个孩子时提升孩子并去除根上方无用边。保留叶之间的距离不变。
3. **中点定根**：选取距离最远的叶对（并列时按排序后的叶名对字典序取最小），
   从字典序较小的叶沿路径走半程：
   - 落在一入一出边内部时拆边，两侧长度保持总长不变；
   - 遇连续零长边时，取从较小叶走来**首先到达**的半程节点；
   - 中点恰为叶节点（只可能出现在全零树）时，该叶以零长边接入新根，身份保留。
4. **导出**：Newick 子树按最小叶名字典序排列，输出确定；CSV 为对称距离矩阵，
   叶名按字典序排列。需要引号的名称（含空格、引号等）会加单引号并双写内部引号，
   含空格的名称身份在往返解析后保持不变。

## 关于根位置的说明

中点定根只是把根放在最远叶对路径的中点，使根到两侧的最远叶距离相等。
**根的位置不代表祖先时间**：它不依赖分子钟假设之外的任何时间信息，
也不能用来推断分歧年代；若需要时间树，请使用专门的定年方法。

## 测试

```sh
python -m unittest test_newick_workbench.py -v
```

覆盖引号标签（含双写引号与下划线转换）、多分叉、注释、非法输入、剪枝距离保持、
边内/节点/叶处中点定根、连续零长边、全零树以及导出往返一致性。
