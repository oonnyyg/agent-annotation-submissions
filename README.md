# binary-meta-analysis

离线研究数据整理工具：对二分类结局（事件/非事件）的多项研究做 Meta 分析汇总，
并执行留一（leave-one-out）敏感性分析。仅提供统计计算，不输出任何决策建议。
仅使用 Python 标准库（要求 Python ≥ 3.12）。

## 输入格式

CSV 文件，每行一项研究，列如下（顺序不限，需含表头）：

| 列名 | 含义 |
| --- | --- |
| `study_id` | 唯一研究编号 |
| `exp_events` / `exp_nonevents` | 实验组事件 / 非事件人数 |
| `ctl_events` / `ctl_nonevents` | 对照组事件 / 非事件人数 |

计数必须为非负整数，每组总人数必须为正；重复编号或非法计数会给出具体行号报错。

## 使用方法

```bash
python cli.py studies.csv --json report.json --csv report.csv
```

至少指定 `--json` 或 `--csv` 之一。JSON 报告包含：纳入/排除研究数及排除原因、
逐研究效应与两类权重（百分比）、固定/随机效应合并结果（含 Cochran Q、I²、τ²）、
逐项留一分析结果。CSV 报告以 `section` 列区分各类记录。

## 统计方法

- **效应量**：实验组相对对照组的优势比（OR），在对数尺度上计算方差
  `1/a + 1/b + 1/c + 1/d` 并汇总。
- **零格处理**：两组均无事件或均全部发生事件的研究被排除并记录原因；
  其余研究若四格中任一格为零，则四格统一加 0.5（连续性校正），否则不校正。
- **固定效应**：逆方差加权合并对数 OR。
- **随机效应**：DerSimonian–Laird 法估计研究间方差 τ²（截断为非负），
  以 `1/(v_i + τ²)` 为权重合并。
- **异质性**：Cochran Q、自由度 k−1、I² = max(0, (Q−df)/Q) × 100%。
- **区间**：一律为正态近似 95% 区间，在对数尺度构造后经指数变换得到 OR 区间。
- **留一分析**：每次移除一项研究后，对剩余研究重新估计 τ² 与全部权重
  （不复用全数据权重）。只剩一项研究时仍给出效应区间，但异质性标记为不可估计；
  无剩余研究时明确报告无结果。

## 方法限制

- 正态近似区间在小样本或极端比例下可能不准，未提供精确法或 Hartung–Knapp 校正。
- 0.5 连续性校正是一种简单惯例，会轻微改变效应估计；稀疏数据下结论可能敏感。
- DerSimonian–Laird 估计在研究数少时 τ² 可能明显低估不确定性。
- 未实现发表偏倚检验、亚组分析或 Meta 回归。
- 排除的研究不参与任何汇总，仅在报告中保留记录。
