# 零维连通持久性

该工具读取二维点云与若干非负查询尺度，计算点云随欧氏距离阈值增大而发生的零维连通分量合并。它只使用边连接连通分量，不构造三角形等高维单形，也不计算孔洞。

## 输入

点文件是包含 `id,x,y` 表头的 UTF-8 CSV：

```csv
id,x,y
c,1,0
a,0,0
b,0,1
```

- `id` 必须唯一；不同点允许有相同坐标。
- `x`、`y` 必须是有限数值。
- 点数必须在 1 到 300 之间。
- 输出不依赖 CSV 行顺序，编号按字典序稳定排序。

查询尺度可以是 JSON 数组，也可以是包含 `scales` 数组的对象：

```json
[0, 0.5, 1, 2]
```

尺度必须是有限且非负的数值。当且仅当两点欧氏距离不大于尺度时存在一条边。

## 持久性与代表规则

每个点都在尺度 `0` 出生，形成一个初始连通分量。边按距离递增处理：

- 距离相同的边作为同一批同时处理。
- 一批边可能连通多个既有分量；这些分量只产生一个面向批末状态的合并结果。
- 批末代表取所有被连通分量代表中的字典序最小编号。
- 其他初始编号对应的区间在该批距离死亡；最后存活编号的终点用 `"infinity"` 标记。
- 坐标重合会产生距离 `0` 的合并以及 `[0, 0)` 零长度区间，这些区间会被保留。
- 区间采用左闭右开 `[birth, death)`：在尺度严格小于 `death` 时存活；尺度恰好等于合并距离时使用合并后的状态。

例如三个两两等距的点在该距离处一次合成一个分量，而不是根据输入行序产生两次互相依赖的级联合并。

## 运行

```powershell
python -m persistence.cli points.csv scales.json --output-dir report
```

也可用安装后的命令：

```powershell
pip install -e .
zero-dimensional-persistence points.csv scales.json --output-dir report
```

## 输出

输出目录包含：

- `report.json`：完整结果，包括区间、合并记录和每个查询尺度的分群。
- `intervals.csv`：每个出生分量一行；最后一个分量的 `death` 为空且 `death_marker` 为 `infinity`。
- `merges.csv`：每个被并入批末代表的编号一行。
- `scale_groups.csv`：查询尺度、分群代表和每个成员。
- `scale_summary.csv`：每个查询尺度的分量数及仍存活区间数，二者始终相等。

单点输入同样会输出一个 `[0, infinity)` 区间，并在每个查询尺度报告一个只含该点的分组。

## 测试

```powershell
python -m unittest discover -s tests -v
```

测试覆盖三点等距同批合并、乱序输入一致性、重合点零长度区间、非法输入、单点输入和报告一致性。
