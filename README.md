# 双时态资产归属档案

仅用 Go 标准库实现的本地双时态（bitemporal）设备归属登记系统，不依赖任何数据库服务。

## 两种时间

- **业务时间（valid time）**：归属事实实际生效的日期区间，使用公历 `YYYY-MM-DD`，左闭右开 `[from, to)` 且必须非空。
- **记录时间（record time）**：系统知悉该事实的时刻，以整数秒表示，由提交方显式给出（`-at`），绝不使用本机当前时间替代。成功批次的记录时刻必须严格递增。

迟到补录只影响"以较晚记录时刻回看"的答案；以更早知悉时刻查询的结果永远不变。

## 提交修订

每批一个 JSONL 文件，每行一项修订：

```json
{"device":"d1","unit":"A","from":"2026-01-01","to":"2026-03-01"}
{"device":"d1","unit":"","from":"2026-01-10","to":"2026-01-20"}
```

- `unit` 为空字符串表示撤销该区间的归属。
- 同批同设备的区间不得重叠；整批先校验后应用，任何一项非法则整批拒绝，档案与最后记录时刻均不变。
- 修订只覆盖指定业务区间：原区间两端未覆盖部分保留，空档可被填补；相邻且单位相同的区间在查询结果中合并，但历史修订证据（批次日志）完整保留。

```sh
go build -o register .
./register submit -db reg.json -at 1700000000 batch.jsonl
```

## 查询

```sh
# 某业务日期归谁（以记录时刻 cutoff 为知悉上限）
./register query -db reg.json -device d1 -date 2026-01-15 -asof 1700000000
# 输出 {"device":"d1","date":"2026-01-15","unit":"A","recorded":true}
# 无记录时 unit 为 null、recorded 为 false，与已知归属明确区分

# 某设备的完整业务时间线
./register timeline -db reg.json -device d1 -asof 1700000000

# 比较两个知悉时刻下同一设备的时间线，输出实际变化的最小分段
./register diff -db reg.json -device d1 -from 1700000000 -to 1700003600
# 空档用 "" 表示；相邻且前后值相同的变化段自动合并
```

查询只使用记录时刻不晚于 `-asof` 的修订。

## 存档

`-db` 指定的 JSON 存档包含全部批次日志与 SHA-256 校验和。重载后历史查询与差异结果与内存状态一致；被篡改、截断或结构非法的存档会被拒绝载入。
