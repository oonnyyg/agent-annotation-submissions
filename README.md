# morse-audio-decoder

仅使用 Python 标准库，从单声道 16 位 PCM WAV 录音中解码国际摩尔斯电码
（英文字母与数字），输出大写文本，并保留可回查原录音的时间线。
不调用任何在线识别服务或第三方音频库。

## 运行示例

```bash
python -m morse_decoder recording.wav config.json -o report.json
```

- 退出码 `0`：解码成功，标准输出打印译文，`report.json` 含完整诊断。
- 退出码 `1`：音频可分段但存在无法解释的时长或未知码组，不生成译文，
  错误的时间范围与原因写入 `report.json`。
- 退出码 `2`：音频格式非法、参数非法或输出文件已存在（绝不覆盖已有输出）。

## 配置（JSON）

```json
{
  "dot_duration": 0.06,
  "tolerance": 0.4,
  "window": 0.01,
  "threshold_on": 0.3,
  "threshold_off": 0.15
}
```

- `dot_duration`：点时长，单位秒。不提供自动测速。
- `tolerance`：时长容差，以“单元”计（1 单元 = 点时长）。时长换算成单元数后，
  与目标值之差不超过该值才算匹配；无法唯一解释即报错。
- `window`：RMS 分析窗长，单位秒，不得大于 `dot_duration` 的五分之一。
- `threshold_on` / `threshold_off`：按满幅归一化（±1.0）的启声/停声阈值，
  需满足 `0 <= threshold_off < threshold_on <= 1`。RMS 达到 `threshold_on`
  判为有声，低于 `threshold_off` 判为静音，介于两者之间保持原状态（迟滞）。

## 时序约定

点 = 1 单元，划 = 3 单元，码元内间隔 = 1 单元，字符间隔 = 3 单元，
词间隔 ≥ 7 单元。开头与末尾的静音被忽略；文件结束时仍结算最后一个字符。
全静音录音返回空文本。

## 窗口量化误差

所有时间段边界都对齐到分析窗边界，因此每个有声/静音段的实际起止时间
存在最多 ±1 个窗长的量化误差。选择窗长时需在时间分辨率与 RMS 稳定性
之间折中；强制窗长 ≤ 点时长五分之一可将该误差限制在 0.2 单元以内，
配合小于 0.5 的容差即可把点（1 单元）与划（3 单元）可靠区分。

## 输出 JSON

- `segments`：合并后的有声/静音时间段（秒），可直接回查原录音。
- `characters`：每个字符的码组及音频起止时间（词间隔记为 `" "` 字符）。
- `errors`：无法唯一解释的时长或未知码组，含时间范围与原因。
- `text`：成功时的大写译文；存在任何错误时为 `null`。

## 限制

不要求识别混合语音或强噪声录音；仅支持国际摩尔斯字母与数字。
