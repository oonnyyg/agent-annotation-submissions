# duplex-print-spool

共享打印室本地作业工具（纯 Go 标准库，不连接真实设备）。把文档页选择转换成
可执行的逐纸正反面用纸计划，通过 JSONL 命令交互，打印动作由确认命令模拟，
并在中断续打时保持纸张核算准确。

## 运行

```sh
go run . [-state spool_state.json]
```

从标准输入逐行读取 JSON 命令，向标准输出逐行写入 JSON 响应
（`{"ok":true,"data":...}` 或 `{"ok":false,"error":"..."}`）。
每条成功的命令都会把全量状态原子写入状态文件，进程重启后自动续接进度。

## 命令

| 命令 | 字段 | 说明 |
| --- | --- | --- |
| `register` | `user`, `quota` | 登记或调整用户纸张额度 |
| `submit` | `user`, `job`, `pages`, `ranges`, `copies`, `duplex` | 提交作业并预留全部纸张 |
| `pause` / `resume` | `job` | 暂挂 / 恢复未开始的作业 |
| `confirm` | `job`, `sheet` | 确认第 `sheet` 张（0 基）已打印 |
| `cancel` | `job` | 取消作业，释放未打印预留 |
| `plan` | `job` | 查看逐纸正反面计划 |
| `queue` | — | 查看队列状态（含当前活动作业） |
| `report` | `user`（可空） | 用户用纸报告（额度/已用/预留） |

示例：

```json
{"cmd":"register","user":"alice","quota":100}
{"cmd":"submit","user":"alice","job":"j1","pages":5,"ranges":"1-3,2-4,5","copies":2,"duplex":true}
{"cmd":"confirm","job":"j1","sheet":0}
{"cmd":"report","user":"alice"}
```

## 语义规则

- **选页范围**：`ranges` 形如 `"1-3,5,7-8"`，重叠部分只保留一次，按原文页码
  升序编排；任一范围非法（越界、倒序、非数字）整单拒绝，不改变队列与额度。
- **纸张编排**：逐份生成，每份都从正面开始；双面时奇数末页背面留空
  （`back:0`）。单面每张只印正面。
- **额度核算**：提交时按整个计划预留纸张，`used+reserved+need > quota` 不能
  入队；每次确认把一张预留转为实际消耗；取消只释放尚未打印的预留，已消耗
  纸张与作业历史保留。
- **打印顺序**：单台打印机。正在打印的作业不被抢占；否则按提交顺序处理。
  暂挂仅适用于未开始的作业，暂挂项不阻塞后续待打印项。
- **确认约束**：只能按顺序确认下一张（`sheet` 必须等于已确认张数）；重复确认
  同一张幂等返回、不重复扣纸；跳过未确认纸张、确认非活动作业或已结束作业
  均被拒绝，且不改变任何状态。
- **中断续打**：确认进度持久化在状态文件中，重启后从下一张未确认的纸继续，
  不重新打印已确认内容。

## 测试

```sh
go test ./...
```

覆盖：范围重叠去重与非法拒绝、奇数页双面留空、多份逐份编排、额度预留与
拒绝、确认幂等与跳张拒绝、暂挂不阻塞队列、中断后取消的预留释放、持久化
重启续打。
