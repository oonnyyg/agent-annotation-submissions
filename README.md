# Newick Distance Workbench

用 Python 标准库处理带枝长的 Newick 树：筛选样本（叶）、统一根位置
（中点定根）、导出叶间路径距离矩阵。全程只做树的裁剪与重新摆根，
**不重新推断任何进化关系**，叶间距离在剪枝前后、定根前后严格一致
（内部用 `fractions.Fraction` 精确计算，没有浮点误差）。

## 功能

- **解析**：单棵树；支持多分叉、单引号标签（`''` 表示字面引号）、
  不嵌套的 `[...]` 注释。每条非根边必须有有限非负长度；根枝长只能
  省略或为零；叶名非空且唯一；内部标签可选。未加引号的下划线按
  Newick 规则转为空格；加引号的名称（含空格）原样保留身份。
- **距离矩阵**：叶间路径距离，共享祖先到根的路径只计算一次。
- **剪枝**（`--keep`）：保留指定叶（至少两个，必须存在），删除其他
  分支；压缩非根的一入一出节点时枝长相加；根只剩一个孩子时提升该
  孩子并去掉根上方的无用边。被移除的内部标签会写入报告，绝不默默
  挪给别的节点。
- **中点定根**（`--midpoint`）：选取距离最远的叶对，同距离时按排序
  后的叶名对字典序取最小；从字典序较小的叶沿路径走半程。落点在边
  内部时拆边且保持总长；遇连续零长边时取从较小叶走来首先到达的半
  程节点；中点恰为叶时，该叶以零长边接入新根并保留身份。全零枝长
  的树也能处理。
- **导出**：确定顺序的 Newick（子树按最小叶名字典序排列，需要引用
  的名称自动加单引号）和 CSV 距离矩阵（叶名排序，精确小数）。

## 用法

```bash
python -m newick_workbench TREE.nwk \
    [--keep LEAF [LEAF ...]] [--midpoint] \
    [--newick OUT.nwk] [--csv OUT.csv] [--report LABELS.txt]
```

- 不给 `--keep` 则不剪枝；不给 `--midpoint` 则不定根。
- 不给 `--newick` 时 Newick 写到标准输出。
- 被移除的内部标签默认写到标准错误，可用 `--report` 指定文件。

示例：

```bash
python -m newick_workbench samples.nwk --keep s1 s3 s7 --midpoint \
    --newick pruned_rooted.nwk --csv distances.csv
```

## 关于根位置的说明

中点定根只是把根放在最长叶间路径的中点，便于统一比较和可视化。
**根的位置不代表祖先时间**：它由现有枝长决定，不假设分子钟，也不
推断任何节点的真实年代或演化方向。若需要有时间意义的根，请使用
专门的定根方法；本工具有意不做任何进化推断。

## 测试

```bash
python -m unittest discover -s tests
```

覆盖引号标签（含双写引号）、多分叉、边内定根、连续零长边、全零
枝长、叶中点、剪枝距离保持以及 CLI 端到端流程。
