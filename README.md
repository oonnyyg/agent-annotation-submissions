# ellipsoidal-route-sampler

离线路线规划工具：仅用 Python 标准库，把有序经纬度航点转换为椭球（Vincenty）
分段距离，并按整条路线的累计里程做等间隔采样。计算过程可通过输出文件检查
和复现。

## 运行方法

需要 Python 3.12+，无第三方依赖。

```
python -m route_sampler waypoints.csv settings.json --out-dir out
```

退出码：`0` 全部成功；`1` 输入非法（错误信息含路线与行号）；`2` 部分路线
未收敛（其余路线结果仍完整输出）。

运行测试：

```
python -m unittest discover -s tests
```

## 输入

航点 CSV（列 `route_id,lat,lon`，同一 `route_id` 的行按文件顺序构成一条路线）：

```
route_id,lat,lon
alpha,31.2,121.5
alpha,35.7,139.7
```

设置 JSON（`ellipsoid` 省略时使用 WGS84）：

```json
{
  "ellipsoid": {"a": 6378137.0, "f": 0.0033528106647474805},
  "sample_spacing_m": 10000.0,
  "tolerance": 1e-12,
  "max_iterations": 200
}
```

- `a`：正长半轴（米），必须为正有限值。
- `f`：扁率，必须满足 `0 <= f < 0.01`。
- `tolerance` / `max_iterations`：Vincenty 迭代的收敛精度与次数上限，显式可控。
- 经纬度为角度，长度为米，不考虑高程。

## 输出

写入 `--out-dir`：

- `segments.csv`：每段起止坐标、距离、起点方位角（零长度段为空，表示未定义）、
  累计里程区间与路线状态。
- `samples.csv`：采样点序号、经纬度、累计里程、所属段号。
- `diagnostics.json`：椭球与迭代参数回显、每条路线的总里程、采样数及失败段
  （段号与 CSV 行号）。

## 计算规则

- 相邻航点用 Vincenty 反解求距离与起点方位，段内位置用 Vincenty 正解生成。
- 经度统一到 `[-180, 180)` 左闭右开区间，支持跨日期变更线；方位统一到
  `[0, 360)`。
- 采样目标是整条路线的绝对累计里程，步长余量自然跨段延续；最后补入终点且
  不重复；连续重合航点不增加里程；全程重合只输出一个位置。
- 边界采样的段归属固定：累计距离 `d` 归属于首个满足 `cumulative_end >= d`
  的正长度段，即共享边界上的采样属于前一段，终点属于最后一个正长度段。
- 极点航点（纬度 ±90）、非有限值、非法参数一律拒绝，错误定位到路线与行。
- 近对跖等未收敛情形只标记失败段：该路线不输出总里程与采样，绝不回退到
  球面距离；其他路线独立完成。

## 精度限制

- Vincenty 方法精度约为亚毫米级，但在近对跖点上迭代可能不收敛；本工具选择
  显式报失败而不是近似替代。
- 采样点由分段正解生成，其累计里程与目标值的偏差受迭代精度（默认 1e-12
  弧度）限制，通常在微米量级。
- 扁率限制在 0.01 以内，不适用于极端扁率椭球；不考虑高程与大地高转换。
