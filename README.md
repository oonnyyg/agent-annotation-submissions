# tzaudit — TZif 转换审计工具

`tzaudit` 读取一个本地 TZif（RFC 8536）时区文件，依据其中的**六十四位（第二）数据块**
回答“绝对时刻 ↔ 本地钟面时间”的核对查询。仅使用 Go 标准库；**不读取操作系统时区
数据库，不访问网络**。

## 运行

```
go run ./cmd/tzaudit <query.json>
```

结果以 JSON 写到标准输出。文件审计失败（截断、乱序、闰秒等）时，错误信息包含
相关**字节位置**并以非零状态退出。

## 输入格式

```json
{
  "zone_file": "examples/sample.tzif",
  "queries": [
    {"type": "at", "unix": 2200086400},
    {"type": "local", "local": "2039-09-20T07:20:00"},
    {"type": "intervals"}
  ]
}
```

- `zone_file`：本地 TZif 文件路径（相对当前工作目录）。
- `queries`：批量查询数组，彼此独立，逐项返回 `ok` 或 `error`。
  - `at`：把 unix 秒（绝对时刻）转换为本地时间，返回 `local`（UTC 钟面读数）、
    `offset`（秒）与 `abbr`。转换瞬间（`unix` 恰好等于某条转换记录）使用**新类型**。
  - `local`：把本地钟面时间（`YYYY-MM-DDTHH:MM:SS`，朴素读数）反查窗口内**全部**
    对应绝对时刻，按时间升序返回 `matches`。正向跳变造成的空缺返回 `gap`
    （`start_local` 含、`end_local` 不含）；回拨造成的重复保留全部候选，不自动挑选。
  - `intervals`：列出窗口内各恒定偏移区间 `[start_unix, end_unix)` 及边界处的
    偏移、缩写与 DST 标记。

## 有效窗口

服务窗口为**首次到末次六十四位转换记录的左闭右开区间** `[first, last)`。
文件必须至少包含两次转换。窗口外的 `at` 查询被明确拒绝（`outside service
window`），不会假装末次偏移永久有效；尾部 POSIX 风格未来规则不予解释。

## 审计规则（解析即校验）

- 仅支持 v2、v3 文件，使用其双数据块中的 64 位块；v1 块仅用于定位第二块。
- 校验两个块的长度与文件大小，截断即拒绝。
- 转换记录必须严格递增；类型下标必须小于 `typecnt`；缩写下标必须在字符表内
  且以 NUL 结尾。
- 带闰秒记录（`leapcnt != 0`）的文件一律拒绝。
- 所有错误均报告相关字节偏移。

## 语义说明

- 偏移计算只使用记录中的 `utoff`，**不使用 DST 标记代替偏移**，也不假设偏移
  变化总是一小时（测试覆盖 30 分钟跳变与 2038 年之后的转换）。
- 本地时间以“把 UTC 钟面读数当作本地读数”的方式表示，避免引入任何系统时区。

## 不支持的特性

- TZif v1（无 64 位块）及 v4+ 文件。
- 闰秒（正/负）数据。
- 尾部 TZ 字符串未来规则的求值；窗口外时刻一律拒绝。
- 操作系统时区库与网络时区数据。

## 示例

`examples/sample.tzif` 为合成时区（+08:00 → +08:30 → +08:00，转换均在 2038
年之后），`examples/query.json` 演示三种查询。运行：

```
go run ./cmd/tzaudit examples/query.json
```
